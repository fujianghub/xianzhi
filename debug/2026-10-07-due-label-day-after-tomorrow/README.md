# 截止日期在后天时显示成「现在 / 24小时后」

- 日期：2026-10-07
- 影响范围：client
- 严重度：medium
- 相关：ADR-0053（详情截图时发现）；REQ-TASK-017

## 症状

任务行日期胶囊、Peek、任务详情「截止」：截止在**后天**的任务显示「现在」「24小时后」「3小时前」之类的相对时间，而不是日期；今天 / 明天 / 昨天与更远的日期正常。

## 复现

1. 建一个截止 = 当前时刻 + 2 天的任务（或后天任意时刻）。
2. 任务页看该行日期胶囊 → 「现在」（恰好 +48h）或「N小时后 / 前」。

## 根因

`src/client/lib/time.ts` 的 `dueLabel`：今天 / 明天 / 昨天之外调用 `displayTime(d, new Date(now + 2 天))`，想借「离 now 超过一天就走绝对日期」的分支强制输出日期。但参照点被挪到了 now + 2 天，后天的截止与这个参照点相差不到 24 小时，`displayTime` 反而走进相对时间分支。

## 修复

`dueLabel` 在今天 / 明天 / 昨天之外直接按用户时区格式化绝对日期（同年省略年份），不再借 `displayTime`。

## 验证

- `src/client/__tests__/time-optimistic.test.ts`「REQ-TASK-017 截止短标签：后天及以后一律绝对日期」：后天同一时刻 / 后天上午 → `9月26日`，大后天 → `9月27日`，前天 → `9月22日`，跨年 → `2027年1月5日`。
- 回归面：`dueLabel` 只用于截止类短标签（任务行、看板、Peek、详情、日期胶囊的 aria-label），今天 / 明天 / 昨天分支不变。
