# 完成分组里最后一条任务后，「撤销」条随分组一起消失

- 日期：2026-10-01
- 影响范围：client（任务页 / 今日页）
- 严重度：medium（误点完成后无法撤销）
- 相关：ADR-0045 §C.15

## 症状
在任务页某个分组（或今日的某个分段）里勾选完成**最后一条**任务：行淡出后整个分组消失，列表里的「撤销」条也不见了；视图里只剩这一条时，整页直接换成空状态插画。e2e `tasks-page.spec` 在只含一条任务的标签视图里找不到「撤销」按钮。

## 复现
今日页只有一个「今日到期」任务时勾选它；或任务页进某个只有一条任务的清单 / 标签视图勾选它。

## 根因
撤销状态（`undo`、`leaving`）存在 `TaskList` 组件里。完成后列表查询（只取未完成）不再返回该任务，父组件按「组为空就不渲染」把 `TaskList` 卸载，状态随之销毁。只用 effect 在「变空」后置一个保留标记也不够：变空的那一次渲染已经先把列表卸载了。

## 修复
`hooks/useLinger.ts`：计数从有变空后保留 8.5 秒（覆盖 8 秒撤销期），并在**渲染时**同步判定「刚才还有、现在空了」（`had.current && count === 0`）。任务页 `GroupBlock` 与整页空状态、今日页 `TodaySection` 与整页空状态都改用它。

## 验证
`e2e/tasks-page.spec.ts` REQ-TASK-025：在只含该任务的标签视图里勾选完成 → 行移出 → 点「撤销」→ 行回来。
