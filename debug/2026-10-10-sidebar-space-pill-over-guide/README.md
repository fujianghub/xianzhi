# 侧栏大类分区里的空间：当前项胶囊伸出引导线

- 日期：2026-10-10
- 影响范围：client（侧栏 `SpaceSwitcher` 大类分区）
- 严重度：low（视觉）
- 相关：REQ-UI-053；ADR-0058 §A；ADR-0015

## 症状

点开大类分区里的空间（如 xianzhi、jianzhai），侧栏里该行的翡翠胶囊（当前项底色 + 描边）左缘压在分区引导线左侧，引导线从胶囊边框里穿过，看起来框「跑到了外面」。悬停底同样如此。个人空间（无引导线）正常。

## 复现

1. 建大类「研发」，把空间 xianzhi 放进去。
2. 1440 宽打开 `/spaces/xianzhi/home`。
3. 量：行 `a[data-active]` 左缘 x = 24，`.xz-guide` x = 26。

## 根因

分区包裹层 `relative ps-3`（12px），引导线 `inset-inline-start: 14px` 对齐展开指示中心。行从内容区起算 = 12px，比线还靠左 2px；胶囊画在整行上，左缘自然压过引导线。目录树（`TreeGuides`）把线画在行内（行自带缩进），不受影响。

## 修复

`SpaceSwitcher` 分区包裹层改 `ps-5`（20px）：行从线右侧 5px 起，线位置不变。

## 验证

- e2e `e2e/sidebar-copy-title.spec.ts` REQ-UI-053：大类分区里当前空间的行左缘 ≥ 引导线右缘 + 4px（旧代码 24 < 27 失败）。
- 截图（日场 / 夜场）：胶囊整体在引导线右侧。
