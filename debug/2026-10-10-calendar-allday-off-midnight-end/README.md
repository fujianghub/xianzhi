# 日历选了 16 ~ 19，19 日却不显示（取消全天留下 00:00 → 00:00）

- 日期：2026-10-10
- 影响范围：client
- 严重度：medium
- 相关：ADR-0057 §B；REQ-CAL-016

## 症状

月视图拖选 16 ~ 19 新建日程，保存后只显示到 18 日，19 日没有。

## 复现

1. 月视图从 16 日按住拖到 19 日 → 编辑器（全天、起 16、止 19）。
2. 取消勾选「全天」→ 起止时刻都是 00:00，日期仍是 16 ~ 19 → 保存。
3. 库里：`all_day=false, start_at=16 00:00, end_at=19 00:00`（本机 `xz` 的「职场建设-青岛尚合联创」即此）。

## 根因

拖选新建的全天表单起止时刻来自零点（`initialForm` 取 `start` / `end` 的分钟数 = 0）。`EventEditor` / `QuickEdit` 的「全天」开关只改 `allDay` 与结束日，不动时刻，于是变成定时 `16 00:00 → 19 00:00`。结束时刻是不含的（`endDay = end − 1ms` → 18 日），所以 19 日不显示——显示逻辑没错，错在表单给了用户不会想要的结束时刻。

## 修复

`model.ts` `toggleAllDay()`：取消全天且起止都是 00:00 时改为 09:00–10:00、日期不变；编辑器与快速编辑共用。已存的数据不自动改。

## 验证

- unit `src/client/__tests__/calendar-lanes.test.ts` REQ-CAL-016：00:00 → 09:00–10:00、已有时刻不动、打开全天结束日不早于开始日。
- e2e `e2e/calendar.spec.ts` REQ-CAL-016：拖选周二 ~ 周五 → 取消全天 → 时刻 09:00 / 10:00、日期不变 → 保存后连续条 `data-days` 覆盖到周五。
