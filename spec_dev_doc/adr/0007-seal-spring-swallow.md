# ADR-0007 燕印改为「晨光白燕」，品牌副标改为诗句

> 状态：已采纳 · 2026-09-25 · 部分取代 ADR-0005 §2 燕印的配色与造型（「翡翠渐变底 + 深墨色衔枝燕剪影」）；燕印的形制（圆角方印、28 / 42 / 56 三档、`--xz-shadow-seal` 投影与内高光、宿主 hover 轻转、减弱档静止、使用位置）不变。

## 背景

旧燕印是翡翠渐变方块上一块深墨剪影，有三个问题：

1. 尾巴几乎不分叉，读起来像鸽子，燕子的剪刀尾和镰刀翼没有体现。
2. 「衔枝」只是一根直线加一片叶，32px 以下看不见，品牌名的意思丢了。
3. 翡翠平涂加深墨，科技感重，缺少春天和自然的气息。

用户要求往「更春天、更自然」的方向优化（2026-09-25 会话）。

## 候选方案

| 方案 | 做法 | 结论 |
|---|---|---|
| A 春光翡翠 | 保留深墨燕，底色左上注入嫩黄绿春光 | 改动最小，但燕子仍很重，春天感有限 |
| **B 晨光白燕** | 翡翠深渐变底 + 右上晨光，暖白燕，褐枝嫩芽 | **采纳**：最轻盈；翡翠主色完整保留；夜场侧栏里最醒目 |
| C 家燕本色 | 浅春绿底，墨蓝燕带栗色喉、米白腹 | 最写实，但翡翠退为点缀、品牌色变弱；颜色多，16px 糊 |
| D 柳梢春燕 | 白燕 + 右下柳梢新芽 | 元素太多，64px 以下柳叶成噪点；留给插画使用 |

候选对比页：2026-09-25 会话的 Artifact「衔枝燕印候选」（含侧栏 28px、标签页 16px 的实际尺寸预览）。

## 决定

1. **造型**：重画燕子。燕身带深分叉剪刀尾，上下两片镰刀翼，头部圆润；口衔一根褐色弯枝，枝上有嫩芽。64 × 64 坐标，外层 `translate(3.6 8.6) scale(.82)` 居中。
2. **按尺寸分级**：`md`（42，侧栏）和 `lg`（56，登录页）用完整版，三片嫩叶，右上有晨光径向渐变。`sm`（28）和 `favicon.svg` 用小尺寸简化版：枝加粗，只留一片放大的嫩叶，没有晨光。
3. **配色走独立 token `--xz-seal-*`**，只在 `:root` 定义，两主题同值（品牌标识不随主题变）：

   | token | 值 | 作用 |
   |---|---|---|
   | `--xz-seal-from` / `--xz-seal-to` | `#14C98A` → `#028F5E` | 方印 135° 渐变（比 `primary-gradient` 深一档） |
   | `--xz-seal-sun` | `rgba(244, 255, 184, .7)` | 右上晨光（仅 md / lg） |
   | `--xz-seal-bird` | `#FFFDF4` | 暖白燕 |
   | `--xz-seal-bird-shadow` | `rgba(3, 77, 51, .35)` | 燕与枝叶的 0.5px 投影 |
   | `--xz-seal-twig` | `#7A4A22` | 枝 |
   | `--xz-seal-leaf` / `--xz-seal-leaf-2` | `#E4F76A` / `#C4EE55` | 嫩叶两色 |

   燕印不再使用 `--xz-primary-gradient` 和 `--xz-primary-fg`。原因是夜场的 `--xz-primary` 为 `#2EE79C`，暖白燕压在上面约 1.5:1，看不清。
5. **燕子占比**：外层变换从 `scale(.82)` 调到 `translate(.5 7) scale(.9)`，燕子更饱满，56px 下枝叶可辨。
6. **品牌副标统一为「日衔寸枝，岁成一巢」**：侧栏和登录页的 ~~`Xianzhi`~~ 与登录页口号 ~~「一枝一枝，衔成自己的巢」~~ 合并为一句原创小句（i18n `app.tagline`，文楷 `--xz-font-display`、`fg-muted`；侧栏 12px、登录页 14px）。意思是每日衔一寸枝，一年成一巢，对应每天一点的记录与学习日积成巢。用户在 4 个候选中选定，其余为「积枝成巢，积日成春」「衔得一寸春光，筑成心上的巢」「一枝一叶总关春」。过程中试过白居易「谁家新燕啄春泥」作副标，用户决定去掉。英文名 `Xianzhi` 只保留在浏览器标题和 favicon `<title>`。
7. **对比度闸门**（`scripts/check-contrast.ts`）：`seal-bird / seal-to ≥ 3`（实测 4.05），`seal-bird / seal-from ≥ 2`（2.11），`seal-leaf / seal-to ≥ 3`（3.50）。Logo 豁免 WCAG 1.4.11，这几项只用来防止调色回归。

## 后果

- 燕印从「深墨压翡翠」变为「暖白飞过翡翠」，和简斋的方印更好区分。
- 暖白燕在渐变浅端只有约 2:1。靠渐变深端、0.5px 投影和剪影轮廓保证可辨，16px 下仍能认出燕子和嫩叶。
- 柳梢构图（方案 D）不进图标，留给登录页大图和空状态插画，并与顶栏枝线呼应（未排期）。
- PWA 图标 192 / 512 / maskable（`04` §9）仍待补，届时按本 ADR 的完整版出图。
