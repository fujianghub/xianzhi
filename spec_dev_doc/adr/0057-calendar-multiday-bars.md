# ADR-0057 日历跨天日程画成连续条 · 取消全天给默认时刻

> 状态：已采纳 · 2026-10-10 · 修订 ADR-0009（月视图 / 全天行逐格各画一块）、ADR-0010（拖选新建全天日程后的「全天」切换）。无迁移。需求区 00：REQ-CAL-015、REQ-CAL-016。

## 背景

用户（2026-10-10）：「日历这里我选择了 16 ~ 19 的日历，但是最后 19 日没有在日历中显示；此外对于这种连续的日历，中间是不是可以链接起来，而不是单独隔开（类似于 Mac 电脑日历显示）。」

1. **19 日不显示**：库里这条是**非全天**日程 `16 00:00 → 19 00:00`（Asia/Shanghai）。月视图拖选 16 ~ 19 打开的是全天表单（起止时刻都是 00:00）；取消「全天」时表单保留 00:00，结束落在 19 日零点 = 18 日结束，19 日自然不显示（模型 `endDay = end − 1ms` 是对的）。编辑器与快速编辑气泡的「全天」开关同病。
2. **不连续**：月视图每格各自渲染一块；周 / 日视图全天行每列各自一列表——跨天日程在每天各出一块，同一条在不同格的上下位置也不一致。

## 决定

### A. 连续条（REQ-CAL-015）

1. `model.ts` `layoutBars(items, keys)`：`keys` 为连续日期（月视图一周 / 周视图全天行）；覆盖这段的每项切成本段 `[c0, c1]`，记 `contL` / `contR`（从前一段延续来 / 延续到下一段）；按 `sortItems`（多日优先、全天优先、再按开始）依次放进最上面一条放得下的行（lane）。单日项同样占行，保证同一天的上下顺序一致。
2. **月视图**：每周一行是一个网格（7 列；行 = 日期行 1.875rem + 各 lane + 可选「还有 N 项」行 + 填充）。格子（`cal-day`，背景、点击新建、拖选、日期行）铺满整列；日程条是兄弟网格项，`grid-column` 横跨多列、`z-index` 压在格子之上，相邻格子的竖线被连续条盖住。每格最多 3 行，被挤下去的在该列显示「还有 N 项」（`cal-more`，点进日视图）。
3. **周 / 日视图全天行**：同一套 `layoutBars`，行数不设上限。
4. **延续端**：跨周（或超出周视图范围）的那端画成直角，左端延续时不画色条、不留外边距——视觉上与上一周的那段接上（同 macOS）。
5. **拖放改期**：放置事件挂到「一周一行」上，按指针所在列算日期（落在日程条上也能算）；拖动起点按抓住的是条上的哪一天计算偏移。
6. `ItemChip` +`bar`（`data-days` 空格分隔本段覆盖的日期、`data-cont-left` / `data-cont-right`）；跨天项的读屏 / title 时间从「全天」改为「M/D–M/D」。

### B. 取消全天给默认时刻（REQ-CAL-016）

7. `model.ts` `toggleAllDay(form, allDay)`（编辑器与快速编辑共用）：取消全天时若起止时刻都是 00:00，改为 09:00–10:00，日期不变——16 ~ 19 取消全天后 = 16 日 09:00 → 19 日 10:00，19 日照常显示；已有时刻不动；打开全天时结束日不早于开始日。
8. 已存的 `16 00:00 → 19 00:00` 数据不自动改（无法判断用户本意），由用户在编辑器里改结束日 / 时刻。

## 候选与否决

- **结束时刻为次日 00:00 的定时日程也算进结束日**：与 iCal / macOS 语义不符（结束 = 不含），会让「23:00 → 次日 00:00」的日程在次日多出一块。否决，从源头（全天切换）修。
- **连续条用绝对定位叠一层**：要同步格子高度、日期行高度、滚动与窄屏换算；同一网格内排布无需任何测量。
- **日程条仍放在格子 DOM 内，用超宽宽度溢出到右侧格子**：依赖内边距 / 边框宽度换算，窄屏与 sm 断点下易错位，且格子需去掉 `overflow-hidden`。否决。
- **月视图每格固定只显示 2 行 + 「+N」（macOS 做法）**：维持现有 3 行 + 「还有 N 项」，与 REQ-UI-031 的既有口径一致。
