# ADR-0066 正文链接改用「宝蓝」

> 状态：已采纳 · 2026-10-30 · 修订 ADR-0065 §1（链接色值）。无迁移。需求区 00：REQ-LINK-011 不变（仍按 `--xz-link` 断言）。

## 背景

用户（2026-10-23 上线 ADR-0065 后）：「颜色不够鲜艳，继续优化」。线上默认玻璃强度是流光，ADR-0065 为保最浅玻璃底 ≥ 4.5 把日场预设加深成 `#00489a`（偏藏青），夜场 `#8ccaff` 偏淡发白。

## 决定

1. 按色相逐档探测：饱和度 100%，日场从亮往暗、夜场从暗往亮，取第一个让 `check-contrast` 全矩阵（纸面 / 阅读纸张 / 最坏玻璃底 / 全部玻璃强度预设）通过的值。日场越靠近纯蓝越能在高饱和下达标，夜场越偏天蓝越能达标。
2. 出四组对比（现状、A 宝蓝 `#003de6 / #33c2ff`、B 电光蓝 `#0031f5 / #52bfff`、C 经典链接蓝 `#0046d1 / #66bdff`），在实页（流光玻璃，日 / 夜场）截图比稿；用户选 **A**。
3. `--xz-link`：日场 `#003de6`、夜场 `#33c2ff`，基础值与玻璃强度预设同值（预设不再另行加深；夜场预设块仍覆盖回来）。主题样式表的起点色同步换成这两个值，再按主题底色推到 ≥ 4.5。

## 影响

- 只改色值；选择器、图标、点击行为同 ADR-0065。
