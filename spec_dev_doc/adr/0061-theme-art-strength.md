# ADR-0061 主题图片强度：淡 / 中 / 浓（默认中）

> 状态：已采纳 · 2026-10-12 · 修订 ADR-0059 §8（遮罩 / 玻璃不透明度改为分档）、ADR-0049（外观偏好 +`skinArt`）。无迁移。需求区 00：REQ-UI-065。

## 背景

用户（2026-10-12）：「为什么只是显示了颜色风格，而没有显示具体的图片内容」。实测（星轨晕环、main 代码）背景图 200 正常加载，但被层层盖住，平均只透出 13% ~ 18%：

1. 图上底色遮罩夜场 0.55 / 日场 0.62（ADR-0059 §8 为可读性调厚）；
2. 内容卡片 `.paper` 完全不透明（主题生效时移除了 `data-glass`，`--xz-paper-bg` 回落实底），约占屏幕 40%；
3. 侧栏 / 顶栏玻璃 0.7 ~ 0.8 加模糊，约 20%；
4. 只有卡片缝隙和页边直接见图，约 25% ~ 35%，而且已被压暗。

给了四个方向（遮罩调薄 / 卡片半透明 / 图片强度档位 / 只在首页大图），用户选「图片强度档位，默认中」。

## 决定

1. **外观偏好加 `skinArt`**：`soft`（淡）· `medium`（中，内置默认）· `strong`（浓）。随账号保存，工作区可设默认（ADR-0049 链路，`PATCH /me/preferences`、`PATCH /workspace` 的 `settings.appearance.skinArt`）；`null` = 跟随默认。只在主题生效时起作用。
2. **页面属性** `html[data-skin-art]`：各档都写（默认档也写，主题样式表按它选材质）；本机 `xz:skin-art` 只作首帧缓存、默认档不存，`theme-init.js` 首帧写属性。
3. **材质分档**（生成器 `src/shared/skins.ts` 的 `SKIN_ART`，按主题 surface / canvas 染色）：

   | 档 | 遮罩 夜 / 日 | 玻璃 thin / regular / thick | 内容卡片 `--xz-paper-bg` | 文字光晕 |
   |---|---|---|---|---|
   | 淡 | 0.55 / 0.62 | 0.6 / 0.7 / 0.8（日场 0.58 / 0.68 / 0.8） | 实底 | 无 |
   | 中 | 0.28 / 0.45 | 0.52 / 0.62 / 0.72（日场 0.5 / 0.6 / 0.72） | 0.9 | 有 |
   | 浓 | 0.12 / 0.3 | 0.4 / 0.5 / 0.6 | 0.78 | 有 |

   日场遮罩比夜场厚：日场插画多为中等明度，比底色暗得多；试过日场中档 0.32，直接压在图上的浅灰导航 / 日期字发虚，0.45 起清楚（夜场插画本身偏暗，浅字压在上面没问题）。
   样式表：基础块 = 中档；`[data-skin-art="soft|strong"]` 块覆盖；减弱透明度（系统 / 手动档）块放最后、特异度不低于档位块，仍改实色。记录正文阅读纸面（`.paper.xz-reading`）各档都是实底。
4. **文字光晕**：中 / 浓档 `.xz-main` 挂四层紧贴字形的不透明底色光晕 `text-shadow: 0 0 1px / 2px / 4px / 10px var(--xz-skin-halo)`（地图标注式；继承，只挂一处；半透明单层光晕在日场会把字蒙成一团白雾），直接压在图上的页标题、分组标签、提示靠它托住；`.paper`、输入框、按钮、编辑区、弹窗里置空。淡档 `--xz-skin-halo = transparent`。
5. **对比度口径**：生成器按各档里最薄的玻璃与最透的卡片（叠在底色上）修正文字色到 AA。背景图本身不可知，浓档在图的高亮 / 杂乱处不保证对比度——这是用户选「浓」时接受的取舍；默认「中」卡片 0.9 近实底。
6. **入口**：「设置 → 主题」画廊标题旁的「图片强度：淡 / 中 / 浓」分段单选（原生 radio，`skin-art-<档>`），没选主题时禁用并提示；管理员「默认外观」多一行「图片强度」（`workspace-appearance-skinArt`）；「恢复为工作区默认」一并清掉。

## 影响

- 已选主题的用户升级后默认从原「淡」的观感变为「中」：图更明显，卡片极淡透出背景。要原样可选「淡」。
- e2e：`resetAppearance` 复位 `skinArt`；`e2e/skins.spec.ts` 覆盖禁用 / 切档 / 首帧 / 工作区默认。
- 不做：任意百分比滑杆（三档够用，且每档都要过对比度口径）；按页面区分强度。
