# ADR-0054 就地改清单 / 标签 · 右侧详情坞 · 记录复制 / 移动 · 网页链接卡片 · 屏幕比例适配

> 状态：已采纳 · 2026-10-09 · 修订 ADR-0053 §C（常驻详情栏 ≥ 1280 只在任务页 → 全站 ≥ lg 详情坞）、REQ-LINK-004 与 07 §2.5（一期不抓取外链 / 域名白名单 + pg-boss → 任意公网主机、请求内同步抓取 + 逐跳地址校验）、03 §11.3 第 269 行（单个网址粘贴不抓元数据 → 先成链接再换标题）。迁移 0028（附件唯一约束带上绑定对象）。需求区 00：REQ-TASK-047 · 048、REQ-ENTRY-038 ~ 041、REQ-LINK-007 · 008、REQ-UI-052。

## 背景

用户（2026-10-09）一次提出五项：

1. 清单、标签、列表要所见即所得地改——像状态 / 日期一样直接点，不进详情。
2. 适配市场上常见的屏幕比例。
3. 详细编辑 / 预览支持网页链接的识别与展示（参考简斋）。
4. 记录条目支持复制（克隆）、移动。
5. 详情页面布局：点开详情直接在最右侧展开，不专门跳页，类似滴答清单。

现状：任务行有清单 / 标签时可点胶囊改（ADR-0045），**没有时没有入口**（只能走 ⋯ 菜单）；记录列表的状态 / 日期等可就地改（ADR-0035 §D），**标签列只读**。常驻详情栏只在任务页 ≥ 1280（ADR-0053），今日 / 收件箱 / 空间 / 日历是遮挡列表的模态抽屉，记录列表点标题整页跳转。记录没有复制；移动只在记录页 Aside 的下拉、批量条与 ⌘K。外链只是 link 标记，规范明确一期不抓取远端（REQ-LINK-004）。

## 决定

### A. 就地改清单 / 标签（REQ-TASK-047 · REQ-ENTRY-040）

1. 任务行无清单时悬停露出「+ 清单」、无标签时露出「+ 标签」（与「+ 日期」同一套幽灵按钮 `xz-row-ghost`），点开即对应选择器；只读成员仍可归清单（清单按人，ADR-0044）。testid `task-list-add` / `task-tags-add`。
2. 记录表格标签列：可写行点标签（无标签时悬停「+ 标签」）弹 `TagPicker`，多选草稿在弹层里即时显示，**关闭时整组一次提交**（`PATCH tagIds`，与属性单元格同一条串行队列 `useFieldCommit`，带最新 `ifUpdatedAt`、乐观更新、409 提示）。testid `cell-tags`。

### B. 右侧详情坞（REQ-TASK-048 · REQ-ENTRY-041；修订 ADR-0053 §C）

3. `DetailDock`：fixed 贴在顶栏下方右缘（同 Aside），挂载时给 `<html>` 打 `data-detail-dock`，主区 `padding-inline-end` 让位 `--xz-dock-w`（tokens，默认 26rem，上限 60vw）；左缘把手可拖宽（320 ~ 60vw，方向键 ±32，双击复位），宽度记本机 `xz:dock-w`。同时只显示最后挂载的一个。只在 ≥ lg（64rem）使用；Aside 在坞开着时让位。
4. 任务：`TaskDetailSheet` 默认 `variant="auto"` = ≥ lg 用坞、更窄用抽屉；任务页 / 今日 / 收件箱 / 空间任务 / 日历一致，URL 照旧（`?task=` 或空间详情子路由）。任务页坞开着且 < 1440 收起清单栏（沿用 ADR-0053，阈值由 1280 放宽到 lg）。
5. 记录：列表 / 卡片 / 看板 / 时间线 / 空间首页的记录链接，≥ lg 的普通左键单击改为在坞里打开（全局 `useEntryDock`，不改 URL，换页即关）；⌘ / Ctrl / Shift / 中键、窄屏照常跳整页。坞内 = 标题就地改 · 属性列表 · 协同正文（可编辑，同记录页的 `EntryEditor`）；坞头 = 类型 · 可见性 · 「打开完整页面」· ⋯ 菜单 · 关闭；Esc（焦点在坞内非编辑区或 body）关闭。表格里坞中的那一行高亮（`data-active`）。Peek 的「打开详情」对记录也走坞。
6. 坞开着且宽度 < 1280：**主侧栏自动收起**（侧栏 240 + 坞 ~416 会把列表挤到 ~350px）；此时点侧栏按钮只临时展开，不改记住的偏好；坞关掉即恢复。

### C. 记录复制 / 移动（REQ-ENTRY-038 · 039）

7. `POST /entries/:id/duplicate {spaceId?, parentId?, detach?, title?}`（幂等键）：源须可读（404），目标空间须可读（404）且可建记录（403）。正文从 ydoc（唯一真源）即时派生 → 去掉评论标记 → 新建 gc:false ydoc，同事务写派生列（列表摘要 / 搜索不等首次打开）；从未落库的空文档保持 `ydoc_version = 0`（首次打开照常注入骨架）。类型 / 来源模板 / 属性沿用，空间类型到不了目标空间时降为随笔；可见性：进个人空间 = 仅自己、离开个人空间 = 空间可见；标签只带复制者自己的；流转从新建起算；不带收藏 / 固定 / 归档 / 评论 / 版本 / 手动关联。位置缺省 = 同空间且源在目录里时紧跟在源之后。标题缺省「源标题 副本」。
8. **附件另存一份**：正文引用的附件（图片 `xz:attachment/<id>`、文件节点 `attachmentId`）凡复制者能读的，复制文件（含变体）到新键、新建一行（owner = 复制者，绑到副本）并改写引用——副本不依赖源（源被删 / 30 天清除、副本移到别的空间都不丢图）。读不到 / 文件缺失的保持原引用；超配额 413。因此附件唯一约束由 `(workspace, owner, sha256)` 改为 `(workspace, owner, sha256, target_type, target_id) NULLS NOT DISTINCT`（迁移 0028）；上传去重优先命中绑同一对象的行、其次孤儿行。
9. 菜单：记录 ⋯ 菜单与行菜单加「创建副本」（原地，Toast 带「打开」）、「复制到…」、「移动到…」。位置对话框 `EntryPlaceDialog`：空间（可建记录、未归档）› 目录位置（目录顶层 / 不放进目录 / 某页之下；复制同空间且原记录在目录里另有「紧跟原记录之后」；移动排除自身与子孙）。移动换空间 = `PATCH spaceId`（同 Aside 的可见性调整）再按所选位置 `PATCH move`。

### D. 网页链接识别与展示（REQ-LINK-007 · 008；修订 REQ-LINK-004、07 §2.5、03 §11.3）

10. `GET /link-preview?url=` → `{url, title, description, siteName, favicon}`：登录用户、每人 30 次 / 分钟；进程内缓存（成功 24h、失败 10min，1000 条），浏览器私有缓存 1h。SSRF：只 http / https、默认端口、无凭据、拒 `localhost` / `.local`；DNS 解析后**全部**地址须是公网单播（拒私网 / 回环 / 链路本地 / CGNAT / 云元数据 / 保留 / 组播 / ULA / IPv4 映射与 NAT64 / 6to4 / Teredo），连接用 `lookup` 钉住校验过的地址；不自动跟随重定向，手动 ≤ 3 跳、每跳重新校验；总超时 5s；HTML 只读前 1MB 且只认 text/html、xhtml；图标 ≤ 64KB、按魔数只收位图（不收 SVG），以 data URI 返回（CSP `img-src` 不放开外站）。失败 502 `UPSTREAM`（文案原样返回）、非网页 415、地址不合规 422。
11. 编辑器：
    - **粘贴单个网址**（空选区、不在代码里）→ 先插入「网址文字 + link」，随后异步取标题替换文字（核对文字与 href 未被改过才换）；本站记录链接（`/entries/<id>`）换成记录链接节点。有选区仍给选中文字加链接。
    - **链接气泡**：可编辑时光标落在链接上出现——显示为「链接 · 标题 · 卡片」｜打开 · 复制链接 · 编辑 · 移除。
    - **网页卡片** `linkCard`（块级原子，attrs `url/title/description/siteName`，首次抓到即写回；图标不存、按网址取）：站点行（图标 + 站点名）· 标题 · 描述 · 网址；可编辑时悬停菜单「链接 · 标题 · 刷新 · 打开」、点击只选中；只读点击新标签打开；斜杠「网页卡片」插入空卡片、卡片内输入网址。
    - **只读悬停预览**：只读正文里外链停 400ms 浮出小卡片。
    - 派生：`fullPlain` 输出 `[链接：标题] 网址`；Markdown 导出 `[标题](网址)`、HTML 导出标题链接 + 描述；源码对话框保留为原子块。
12. 视频 iframe 嵌入（B 站 / YouTube）本轮不做：需放开 CSP `frame-src`，与 07 §2 外部嵌入立场冲突，单独决策。

### E. 屏幕比例适配（REQ-UI-052）

13. 常见视口巡检（390×844 / 360×780 / 768×1024 / 1024×768 / 1280×800 / 1366×768 / 1440×900 / 1536×864 / 1920×1080 / 2560×1440 / 3440×1440）× 今日 / 任务 / 收件箱 / 记录 / 日历 / 空间：**任何页面不得出现整页横向滚动**。修：
    - 记录页类型筛选条是 `<fieldset>`（UA 默认 `min-inline-size: min-content`，`overflow-x-auto` 不生效）→ `min-w-0`；
    - 横向滚动容器内的 `sr-only`（absolute）以最近的定位祖先为包含块，逃出滚动容器撑宽整页 → 各横向滚动容器加 `relative`（记录表格、审计 / 通知设置表、看板、任务页范围胶囊条）；
    - 任务页列表在宽屏 / 带鱼屏贴左留大片空白 → 居中，≥ 1920 放宽到 6xl；
    - 手机宽度（< 40rem）记录页未指定视图时默认卡片（表格要横向滚动才看得全），点「列表」显式写 `view=table`；
    - 任务行清单 / 标签胶囊按**行宽**（container query `@lg`）而非视口收放，标题至少留 4rem——坞开着列表窄时让胶囊先让位。

## 候选与否决

- **记录详情坞用 URL（`?entry=`）**：要给每个列表路由加 search 校验，且记录页本身已有 `/entries/:id`；坞是「看一眼 / 顺手改」，刷新回到列表可接受——用全局状态，换页即关。
- **任务详情坞只在任务页**（ADR-0053 的取舍）：今日 / 收件箱 / 空间是最常打开详情的地方，抽屉遮列表正是用户要改的；坞是全局 fixed + 主区让位，不需要各页重排布局。
- **复制保留对源附件的引用**（与粘贴 / 上传去重现状一致）：源被删即刻读不到（`attachment.read` 按绑定对象鉴权）、30 天后文件被清除，副本移到别的空间也读不到——用户会以为「复制」的是独立一份。
- **外链抓取放 pg-boss**（07 §2.5 原案）：卡片 / 取标题是用户在等的交互，排队只增加延迟；风险靠逐跳地址校验 + 钉住解析 + 限流 + 缓存控制。**域名白名单**（原案只放简斋与 GitHub）会让功能对一般网页无效，改为地址校验。
- **og:image 缩略图**：要么放开 CSP `img-src` 让浏览器直连外站（泄露访问者 IP / Referer 给第三方），要么服务端代理大图（成本与 SSRF 面都更大）——只取图标（≤ 64KB data URI）。
