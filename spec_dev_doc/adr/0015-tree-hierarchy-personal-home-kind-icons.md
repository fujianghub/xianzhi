# ADR-0015 目录层级表达、个人空间工作台、记录类型图标

> 状态：已采纳 · 2026-09-26 · 修订 REQ-KB-003（个人空间不再套用产品型概览）、SpaceIcon 未设颜色时的回退色；其余为新增。

## 背景

- 目录树（ADR-0012）三处呈现——空间「目录」页、记录页位置导航（ADR-0014）、侧栏 大类 → 空间——只靠缩进区分层级（24px / 12px / 无缩进），没有引导线、字重不分级，节点前是纯文字类型胶囊，层级一深就看不清归属。
- 个人空间 `/spaces/me-…/home` 没有专门分支，`kind=work` 于是显示 Bug / 迭代 / 版本面板，对个人无意义；用户期望在这里看到「产品开发 / 技术学习规划 / 生活」等大类及其空间的目录。
- 图标大面积 `text-fg-muted`：只有侧栏主导航有 `--xz-icon-*` 专属色，位置导航、面板、树、操作按钮都是灰；记录类型没有图标映射；未设颜色的空间图标回退为灰底灰字。

用户选择（2026-09-26）：参考简斋目录；个人首页 = 大类 → 空间 → 目录总览；树节点用彩色类型图标块；类型图标全站统一。

## 决定

1. **目录层级表达**（REQ-KB-006，参照简斋 `.jz-epub-toc`）：
   - 每级祖先一条 1px 竖向引导线，位于该级展开指示中心；最近一级更深（fg 20% vs 11%），当前行的最近一级为主色。行间不留间隙，线连成一条。
   - 缩进：「目录」页 20px、位置导航 12px、个人首页空间目录 20px；侧栏空间行在大类下缩进一级并带一条分区引导线（分区含当前空间时为主色）。
   - 字重按层级递减：L0 600 · L1 500 · 其余 400；字号与颜色不随层级变。
   - 有子项且折叠时行尾显示直接子项数（`FlatItem.childCount`）。
   - 展开指示按钮悬停主色淡底、按下 `.88`；新出现的子行 `xz-tree-in` 淡入（相对父项错峰 18ms，≤ 8 格），减弱档无动画。
   - 共用：`components/ui/tree-guides.tsx`（引导线 / 字重 / 错峰）与 `components/domain/DirTree.tsx`（懒加载目录树，选择模式 = 位置导航、链接模式 = 个人首页）。
2. **个人空间工作台**（REQ-KB-007）：`isPersonal` 的概览页不再显示 Bug / 迭代 / 版本面板，改为
   - 主面板「空间目录」：大类（按 sort_key，未分类最后）→ 空间 → 目录树；大类默认展开、空间默认收起，展开空间时才请求 `GET /spaces/:id/tree`；展开状态本机 `localStorage xz:home-dir:v1`；空间行链接到该空间概览，目录节点链接到记录。
   - 侧列「个人记录」（个人空间最近 8 条）与「各空间最近更新」（跨可见空间 8 条，带空间标注）。
   - 快捷新建：随笔 · 笔记（学习笔记模板）· 计划（学习计划模板）。
   - 不新增接口：复用 `GET /spaces`、`GET /space-groups`、`GET /spaces/:id/tree`、`GET /entries`。
3. **记录类型图标与色块质感**（REQ-UI-037）：
   - 类型 → Lucide 图标：决策 Scale · 迭代 IterationCw · Bug Bug · 变更 Rocket · 日志 NotebookPen · 随笔 StickyNote · 复盘 ClipboardCheck · 优化 Sparkles · 学习计划 Target；色仍取 `ENTRY_KIND_TONE`（REQ-UI-033）。
   - `KindIcon` / `IconChip` 色块（`.xz-chip`）：色板 `-bg` → 掺 22% `-solid` 的 145° 渐变 + 顶部 `--xz-edge` 高光 + 同色 24% 细描边 + 同色微投影；所在行悬停弹簧放大 1.08 并轻转 −4°，按下 .94；只引用 token（`.xz-tone-<色>` 把色板三件套映射到 `--k-*`）。
   - `KindBadge`：图标 + 类型名胶囊，替换卡片 / 详情页头 / 表格 / 搜索 / 关联 / 时间线 / 概览列表 / 其余记录中的纯文字类型徽章；树与导航里只用色块（旁边有标题，类型名作 `title` 与读屏文本）。
   - 位置导航快捷项沿用侧栏 `--xz-icon-*`（全部 blue · 最近 cyan · 收藏 amber · 已归档 violet · 个人随笔 emerald）；大类行与侧栏分区头用大类色的 Layers 色块；概览面板标题前加彩色色块。
   - `SpaceIcon` 统一为色块；未设颜色时按类型给默认色（项目 blue · 学习 purple · 工作 orange · 个人 green），不再回退灰色。图标选择器用 `plain`（只要字形）。
   - 目录页行内操作悬停带语义色：新建子页 = 主色淡底，移出目录 = danger 淡底。

## 候选与否决

- 简斋式极简（三角 + 叶子圆点、保留文字胶囊）：层级清楚但仍偏灰——用户选彩色类型图标块。
- 个人首页只放个人空间自己的目录：个人空间多为零散随笔，不回答「我的空间都在哪」——用户选大类总览。
- 引导线用 CSS 多重背景渐变（简斋做法）：层级数需在 CSS 里逐级枚举；改为组件按层级渲染绝对定位竖线，深度不设上限。
- 图标色块用实色填充 + 白字：9 色在夜场亮度差异大、白字对比度难统一——保持浅底深字（-bg / -fg 已校验 ≥ 4.5）。

## 后果

- 新增：`components/domain/KindIcon.tsx`、`DirTree.tsx`、`components/ui/tree-guides.tsx`；app.css 新增 `.xz-tone-* / .xz-chip / .xz-kind-badge / .xz-hue / .xz-guide / .xz-tree-* / .xz-twisty`。
- `ENTRY_KIND_TONE` 迁到 `KindIcon.tsx`（EntryCard 重新导出，`entryKindClass` 保留）。
- 视觉基线（`e2e/design.spec.ts`）涉及记录卡片 / 空间图标处需确认后重拍。
