# ADR-0030 记录页编辑外框美化：格式栏卡片化 · 文档栏收敛 · 正文去焦点框

> 状态：已采纳 · 2026-09-29 · 修订 ADR-0028 §2（正文焦点描边）、06 材质表「编辑器吸顶工具栏」「阅读胶囊」两行。参考简斋编辑器工具栏玻璃卡片（`.jz-editor-toolbar`：圆角 10、浅底、细边、34px 按钮）。

## 背景

用户反馈格式仍不美观。对照截图的问题：
1. 格式栏整宽贯穿纸面、上下两条横线，像一条硬横带；满栏时按钮挤在左边、右侧大片留白。
2. 文档栏左右两端分散，阅读胶囊高饱和主色描边抢过其他按钮，层级失衡。
3. 正文获得焦点有一圈描边，看起来像表单输入框。
4. 按钮尺寸 / 圆角不统一。

## 决定

1. **格式栏卡片化**：不再负外边距整宽贯穿，改为纸面内的圆角卡片（`radius-lg`、纸面上叠 surface-2 55%、1px 细边、inset 高光 + 两层轻阴影），吸顶时离顶栏 8px；按钮 30px / 圆角 7px / 图标描边 1.75；组间分隔线 16px 高、fg 12%；「+」26px 主色渐变 + 同色微投影。纸面实底不 blur 的原则不变（06）。
2. **文档栏收敛**：左侧信息标签带小图标（字数 FileText、上次保存 History）；右侧动作组整体靠右，统一 28px 幽灵按钮；阅读胶囊改中性细边、图标 muted，悬停 / 打开时才用主色。
3. **正文不画焦点框**：`.xz-prose[contenteditable=true]:focus-visible { outline: none }`，焦点由光标提示；按钮、输入框等控件的全局 `:focus-visible` 不变（键盘可达性保留）。

## 后果

- 06 材质表两行加注。CHANGELOG。无 REQ 变化（视觉调整），既有 e2e（REQ-EDITOR-024 / 032、REQ-READ-007 等）照常通过。
- 代码：`app.css`（格式栏 / 文档栏 / 按钮 / 胶囊 / 正文焦点）、`EditorToolbar.tsx`（文档栏信息图标）、`zh-CN.ts`（「上次保存」）。
