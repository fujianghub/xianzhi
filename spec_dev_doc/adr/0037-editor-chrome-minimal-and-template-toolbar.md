# ADR-0037 记录页编辑区「文档式 · 极简」· 模板编辑器格式工具栏

> 状态：已采纳 · 2026-09-30 · 修订 ADR-0029 §1（文档栏「阅读」组 = 阅读胶囊四个图标弹层 + 专注 → **单个「阅读」按钮弹层，内分四页**；保存 / Markdown 窄屏只显示图标 → 控件一律带文字）、ADR-0031（格式栏「一行图标 + 下方一条与正文等宽的 1px 细线」→ **细线只在吸顶时出现**）、ADR-0035 §B.8 · §B.9（属性面板两列表单式、流转展开为面板内时间线 → **紧凑属性列表 + 流转摘要弹层**，标签并入列表）、ADR-0023 §4（模板编辑器只有斜杠菜单与气泡工具条 → 加格式工具栏、块手柄与表格工具条）。无迁移。需求区 00：REQ-ENTRY-030 · 031、REQ-READ-010、REQ-TPL-012；REQ-READ-007、REQ-ENTRY-024 · 025 加注。

## 背景

ADR-0035 上线后用户反馈（2026-09-30）：记录页标题与正文之间堆了太多「框」——两列表单式属性面板（每行图标 + 属性名 + 值，标签单独整行）、面板底部可展开的流转时间线（展开后把正文推下去一大段）、文档栏右侧阅读胶囊四个图标 + 专注 + 保存 + Markdown、格式栏常驻底线，前后三条分隔线。正文要滚过半屏才开始。

同时，模板编辑页（`/settings/templates/new`、`/settings/templates/$templateId`）的正文编辑器只有斜杠菜单与选区气泡，写模板时找不到标题 / 列表 / 表格等格式入口，与记录页体验割裂。

## 决定

用户 2026-09-30 在排版方向中选定 **方案 A「文档式 · 极简」**。

### A. 紧凑属性列表（REQ-ENTRY-030；修订 ADR-0035 §B.8）

1. `EntryProperties` 由「图标 + 属性名 + 值」的表单式网格改为**紧凑属性列表**：两列（≥ md，窄屏一列）；每行 = 属性名（淡色 `text-muted`、**无图标**、固定窄标签列约 5.5rem，超长省略号 + `title`）+ 值。值仍为彩色胶囊 / 彩色日期 / 进度条（REQ-UI-044，`FieldValue`），**点值即改不变**（`FieldEditor` Popover，600ms 合并 + `ifUpdatedAt`）。
2. **标签并入同一列表**：作为普通一行（属性名「标签」+ `TagPicker` 胶囊），不再单独占整行、不在值区再写一次「标签」字样。
3. **空属性收起**：空值的非必填字段默认不逐行显示，收为列表末尾一行「+ 显示 N 个空属性」；点开后逐行显示（空值为淡色「空」占位，可点编辑），末尾变为「收起空属性」。展开状态只存在本页内存（不记偏好）。
   - **必填**缺失的字段始终显示，值位为红色「必填」（只提示，不拦）。
   - **只读用户**（不可编辑本记录）直接不显示空属性，也没有「+ 显示 N 个空属性」这一行。
   - 标签为空时同样计入空属性（可编辑者从「+ 显示…」里加标签）。
4. 其余不变：DOM 位置（标题与文档栏之间）、`entry-properties` 测试钩子、专注模式隐藏、无字段类型不显示、不懒加载、按字段数预留高度（预留按「非空 + 必填 + 1 行」计算）。

### B. 流转摘要 + 分组时间线弹层（REQ-ENTRY-031；修订 ADR-0035 §B.9）

5. 流转不再在面板里展开。属性列表下方一行摘要：`↻ 流转 N 次 · 最近 <字段> <旧值>→<新值> · <相对时间> ▸`（旧 / 新值为小号彩色胶囊；N = 事件组数，见下）；没有流转时不显示这一行。
6. 点击摘要弹出 **Popover**（不推开正文；窄屏为底部抽屉），内容 = 按**事件**分组的彩色竖向时间线（新 → 旧）：
   - **分组规则**：同一操作者、相邻两条变化间隔 ≤ 2 秒的多字段变化合为一组（例：批量改状态 + 优先级）。组头 = 色点（取组内第一条新值的色调）+ 操作者 · 相对时间（悬停绝对时间）；组内每条 = 「字段：[旧值胶囊] → [新值胶囊]」，新建起点显示「设为 [值]」。
   - 数据仍为 `GET /entries/:id/field-changes`，分组在前端纯函数完成（`groupFieldChanges`，可单测），服务端不变。
   - 弹层内容过长时内部滚动（最高约 60vh）。

### C. 文档栏：单个「阅读」弹层 + 带文字操作（REQ-READ-010；修订 ADR-0029 §1）

7. 文档栏左侧为安静元信息：`N 字 · 已保存 <相对时间>`（淡色小字，无图标、无按钮外观）；未保存过版本时只显示字数。
8. 右侧控件一律**带文字**的轻按钮（无边框，悬停浅底）：
   - 「Aa 阅读 ▾」：**一个**按钮弹出**单个**弹层，内有 字体 / 纸张 / 排版 / 目录 四个分页（顶部分段切换，记住上次打开的分页于本页内存）；各分页内容与原四个弹层相同。取代原阅读胶囊的四个图标；原 `reading-open-font|paper|layout|toc` 测试钩子改挂在弹层内对应分页按钮上，入口按钮为 `reading-open`。只读者也可用。
   - 「专注」（所有人）。
   - 「保存」「Markdown」（仅可编辑者）；窄屏也保留文字（放不下时收进「…」，不改为纯图标）。
   - 两组之间不再画竖线，以间距分组。
9. **分隔线 3 → 1**：只保留属性块与文档栏之间一条细线（`--xz-divider`）；文档栏与格式栏之间不画线。
10. **格式栏未吸顶时无底线**；吸顶后（哨兵 `data-stuck`）才出现纸色底 + 极淡阴影 + 与正文等宽的底线（修订 ADR-0031）。按钮规格与「…」收纳（ADR-0028 · 0030）不变。
11. **不变**：DOM 顺序 标题 → 属性列表 → 文档栏 → 吸顶格式栏 → 正文；REQ-READ-007 几何 `title.y < docBar.y < toolbar.y`；文档栏不吸顶、随正文滚走；< lg 格式栏由 MobileToolbar 代替。

### D. 模板编辑器格式工具栏（REQ-TPL-012；修订 ADR-0023 §4）

12. 模板新建 / 编辑页的正文编辑器（`TemplateEditor`，非协同 Tiptap）上方显示与记录页**同一个** `EditorToolbar` 格式行（吸顶在顶栏下，吸顶规则同第 10 条）：+ 插入、撤销 / 重做、清除格式、段落格式、加粗…、颜色、列表、引用、对齐、链接。
13. 「+」插入面板与斜杠菜单用**同一份排除清单**：图片、附件、记录卡片、记录链接、源码（Markdown 源码对话框）、模板——这些依赖记录 / ydoc / 附件归属，模板正文不能带（沿用 ADR-0023 §4 的 `exclude`，由 `slash.tsx` 与插入面板共享）。
14. 有块手柄菜单（拖动、转换、复制、删除）与表格工具条（ADR-0025 · 0032）。
15. **不显示文档栏**：模板没有历史版本 / 保存版本 / 专注 / 阅读偏好入口；`Mod+S` 仍是保存模板（03 §11.2 注）。字数不显示。
16. 工具栏依赖的编辑器能力按 `schemaKit` 判断：不在模板 schema 里的命令按钮不渲染（而不是禁用）。

## 候选与否决

- **其余排版方向**：用户 2026-09-30 比较后未选，选定方案 A。
- **流转仍在面板内展开、只是默认收起**：展开时照样推开正文——否决，改为 Popover。
- **流转在服务端分组**：需要新字段 / 新接口，分组只影响展示——前端纯函数足够。
- **阅读仍保留四个图标、只加文字**：一行放不下，窄屏必然收进「…」——合并为一个弹层。
- **空属性一律隐藏、不给展开入口**：可编辑者就找不到空字段去填——否决，保留「+ 显示 N 个空属性」。
- **模板编辑器也显示文档栏（去掉历史 / 保存）**：只剩字数与 Markdown，而 Markdown 源码依赖协同 ydoc——不显示。
