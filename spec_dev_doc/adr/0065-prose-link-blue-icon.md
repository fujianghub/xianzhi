# ADR-0065 正文链接：蓝色 + 前置图标

> 状态：已采纳 · 2026-10-23 · 修订 04 §2.1（`primary-text` 用途去掉「链接」）。无迁移。需求区 00：REQ-LINK-011。

## 背景

用户（2026-10-23）：「链接识别的颜色标识使用蓝色，并且需要添加一个形象的小图标在最前面」。正文链接原为主色翡翠（`primary-text`）+ 下划线，与激活项、标签、按钮文字同色，夹在正文里不够醒目。

## 决定

1. **颜色**：新 token `--xz-link`（日场 `#0063cf`、夜场 `#71b8ff`，同 9 色板蓝的文字档；玻璃强度预设里日场加深为 `#00489a`、夜场 `#8ccaff`——日场预设改了它，夜场预设块覆盖回来）。纸面 / 阅读纸张 / 最坏玻璃底及全部预设矩阵 ≥ 4.5（`check-contrast`）；主题样式表按主题底色把蓝推到 ≥ 4.5（`skinTokens` 的 `--xz-link`）。下划线为链接色 40%，悬停实色。
2. **图标**：`<a>::before` 遮罩 lucide `link`（链条），`mailto:` 换 `mail`（信封）；颜色 = currentColor，不加载图片、不进文字（复制 / 导出不带）。`display: inline` + 内边距撑宽（inline-block 伪元素在可编辑区里会扰乱点击定位）。
3. **范围**：只认 Tiptap 链接标记与 PmView 渲染的 `<a rel~="noopener">`（记录正文、任务描述、评论、Peek、只读正文 / 历史预览）。附件下载、记录卡片、静态查询块等节点视图里的 `<a>` 不带 rel，网页卡片另有 `.xz-link-card`，都不加；查询块结果行链接保持继承色。
4. **点图标**：浏览器在伪元素上的点击定位不稳定（落到链接之前或不动），光标不进链接、链接气泡不出。`LinkBubble` 在 mousedown（捕获）判断落点在图标区（`::before` 内边距 + 右外边距）时接管：阻止默认定位，光标放进链接首字之后并聚焦——与点在文字上一致；键盘、点文字、Shift / 双击不受影响。

## 不做

- 按站点显示 favicon：每个行内链接都要请求预览接口（出站请求 + 隐私），悬停卡片 / 网页卡片已展示站点图标。
- 站内链接（`/entries/…`、`xz:`）换别的图标：记录引用已有 `[[…]]` 胶囊样式（`.xz-entry-link`）。
