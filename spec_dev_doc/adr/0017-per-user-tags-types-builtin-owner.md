# ADR-0017 标签与自定义类型按人隔离、内置类型由所有者统一维护、界面改称「类型」

> 状态：已采纳 · 2026-09-27 · 修订 ADR-0014 §2（标签全工作区共享、「管理员或创建者」可管 → 标签属于个人，只有本人可见可管）、ADR-0016 §3（自定义类型全工作区共享 → 属于个人；内置类型「隐藏」→ 所有者删除 / 恢复；删类型固定转随笔 → 可选转入目标）；其余为新增。

## 背景

用户要求（2026-09-27，两轮讨论后定稿）：

1. 「类型」「标签」按用户隔离：每个人管理自己的。
2. 内置类型统一由所有者（root）添加 / 删除 / 编辑。
3. 界面上「记录类型」改称「类型」。

## 决定

1. **标签完全私有**（REQ-TAG-007）：标签属于创建者（`tags.created_by`），只有本人能看到、打到任务 / 记录上、按它筛选与搜索、改名 / 改色 / 合并 / 删除；管理员不例外。
   - 唯一约束改为 `(workspace_id, created_by, name)`：不同人可有同名标签。
   - 关联表不变；共享的记录 / 任务上各人打各自的标签——读（列表 / 详情的 `tagIds`、任务 `tags`、导出 frontmatter）、写（整组替换只替换本人的、批量增删）、筛选（`tag=`）、搜索（标签名子串）一律按 `tags.created_by = 当前用户` 过滤；打别人的标签 → 422。
   - 新建 = 非 guest（`tag.create`）；管理 = 本人（`tag.manage`）。删号（purge）时其个人标签随之删除。
   - 迁移 0016：无主旧标签（含 seed）归工作区所有者；旧约束保证了同工作区不重名，回填不会冲突。
2. **自定义类型归个人**（REQ-ENTRY-018 · 019）：只有创建者能用它新建记录 / 把记录改成它、能改名改色改状态、能删除（`entry_type.manage` = 本人）；唯一约束同样按人。
   - 读者仍能看到别人记录所用类型的名、色、状态（类型决定记录是什么，隐藏会让共享记录失去意义）：`GET /entry-types` 返回全部自定义类型，每项带 `mine`；管理页、新建菜单、筛选条、批量改类型只列本人的。
   - 修改他人记录的属性（有写权限时）仍按该记录的类型校验，不要求类型是本人的。
3. **内置类型由所有者统一维护**（REQ-ENTRY-020）：新动作 `entry_kind.manage` = 仅 owner。新表 `entry_kind_overrides(workspace_id, kind, name?, color?, deleted)` 取代 `hidden_entry_kinds`（迁移 0014 建表并把原「隐藏」迁为「已删除」，0015 删旧表）。
   - 改名 / 改色：`PATCH /entry-types/builtin/:kind { name?, color? }`，`null` = 恢复默认；与所有者本人的自定义类型重名 409。属性 schema、状态流转、图标、正文模板仍由代码定义。
   - 删除：`DELETE /entry-types/builtin/:kind?moveTo=`，全员的该类型记录（含回收站）转到另一个**内置**类型后标记已删除（不能把大家的记录转进某人的私有类型）；`POST …/restore` 恢复。已删除的内置类型不能新建、不能改成该类型（422），不出现在筛选条 / 新建菜单 / 批量目标。
4. **删除时选择转入目标**：自定义类型 `DELETE /entry-types/:id?moveTo=`（内置类型或本人的其它类型），缺省随笔（删随笔时必须给出）；目标不能是被删类型本身、已删除的内置类型、有无默认值必填属性的类型（迭代 / 变更 / 复盘）。fields 按目标重建，保留仍合法的状态 / 进度；审计沿用 `entry_type.deleted`（内置类型 `targetType = entry_kind`）。
5. **称呼**：设置导航与管理页「记录类型」→「类型」（`/settings/types`）；标识符不变。

## 候选与否决

- 标签「归个人管，但记录的读者可见」：协作感更强，但他人的整理方式会混进自己的视图，不是真正的隔离——用户选完全私有。
- 自定义类型也完全私有：他人查看共享记录时类型变成无名灰块、状态无法解读——否决，改为「管理私有、显示公开」。
- 管理员可管他人的标签 / 类型：用户明确不要例外。
- 仅所有者可管全部标签 / 类型（本 ADR 初稿）：用户随后改为按人隔离，只保留内置类型由所有者维护。
- 内置类型删除时可转进某人的自定义类型：会把全员的记录归入一个人的私有类型——否决。
