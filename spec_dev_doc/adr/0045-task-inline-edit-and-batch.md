# ADR-0045 任务行内编辑 · 单个管理菜单 · 页面级批量管理

> 状态：已采纳 · 2026-10-01 · 修订 08 §2.3 / §2.3b / §2.4 / §2.6（点任务标题打开详情 → 行内改名，「›」/ 回车打开详情）、REQ-TASK-020（键盘 +r / m / Shift+J/K）、REQ-TASK-016（批量 +restore / uncomplete）、REQ-MOBILE-002（长按多选改为页面级）。无迁移。需求区 00：REQ-TASK-037 ~ 041。

## 背景

用户（2026-10-01）：「侧栏的任务支持简要的修改，直接点击就可以修改而不是跳转到详情，元数据也支持直接修改；支持任务的批量、单个管理，比如删除、移动、完成等等」。

现状：点标题即打开详情；行上元数据只读；没有单个任务菜单；多选与批量条是**每个 TaskList 实例各一份**——任务页每个分组一个列表，跨组选择会出现多条批量条叠在一起、无法跨组全选；批量只有改状态与删除；服务端批量无恢复 / 取消完成，删除与完成无法批量撤销。

用户拍板：单击标题 = 行内改名、行尾「›」= 打开详情；全站任务列表（任务页 / 今日 / 收件箱 / 空间列表视图）一致；多选 = ⌘/Ctrl 点击 + Shift 连选 + 页头「选择」模式 + 保留键盘 x / 手机长按，选择改为页面级、可跨分组。

## 决定

### A. 行内编辑（TaskRow，REQ-TASK-037 · 038）

1. 单击标题 → 原位输入框（全选），回车 / 失焦保存、Esc 取消；输入法组词中的回车不提交；输入框的按键不冒泡给列表（空格不会完成任务）、按下不触发拖拽。草稿存 ref，行被虚拟滚动卸载时也保存；结束后焦点收回网格（j / k 继续可用）。键盘：焦点行按 `r` / F2 改名，回车 / `e` 仍是打开详情。
2. 胶囊就地改：日期胶囊（无日期时悬停露出「+ 日期」）→ 日期选择器；优先级旗（无优先级时悬停露出灰旗）→ 优先级选择器；清单胶囊 → 清单选择器；标签 → TagPicker。选择器**点开才挂载**（受控 `open`）；日期与标签在弹层关闭时一次提交（连续改动不各发 PATCH，免得撞 `ifUpdatedAt` 409）。
3. 行尾：悬停 / 键盘聚焦 / 有弹层时显示「⋯」与「›」（触屏常显「›」）；这些按钮与占位**只在需要时渲染**——1 万行列表少挂 DOM（REQ-UI-017 帧间隔 P95 ≤ 20ms）。
4. 写权限按空间角色由列表 / 页面统一算出传入（`useTaskWritable`：`canCreateIn` 且未归档），保存回调由列表传入——行内不各自订阅空间列表、不各自建操作对象（同为万行性能）。只读用户：标题点了打开详情、无日期 / 优先级 / 标签编辑；清单仍可改（私人归类，ADR-0044）。
5. 详情里的子任务（`inline=false`）保持旧行为：点标题打开、无菜单与就地编辑（Esc 会被详情的 Radix 层捕获关掉详情）。

### B. 单个管理菜单（TaskRowMenu，REQ-TASK-039）

6. 行尾「⋯」与右键共用：完成 / 取消完成 · 打开详情 · 日期（今天 / 明天 / 下周一 / 无日期 / 自选…）· 优先级（五个色旗，当前值高亮）· 移到清单… · 标签… · 移到空间 · 状态 · 复制标题 · 删除（Toast 撤销 = restore）。键盘：焦点行按 `m` / ContextMenu 键打开。
7. 右键锚在指针处用 Radix 虚拟锚点：虚拟行与滑动手势都有 transform，`position: fixed` 的锚会错位。触屏长按也会触发 contextmenu → 按最近一次 pointerType 判定，触屏不弹菜单（长按归多选），且长按后屏蔽随后的那次 click。
8. 弹层渲染在 body，但 React 事件仍沿组件树冒泡：网格 `onKeyDown` 只处理 `target === currentTarget` 的按键；行的 mousedown / contextmenu、拖拽激活只认来自行本身 DOM 的事件（`contains(target)`），并排除输入框。

### C. 页面级选择与批量（REQ-TASK-040 · 041）

9. `TaskSelectionScope`（任务页、今日、收件箱、空间列表视图）：zustand store（`selected: id → 任务快照`、`anchor`、`selectMode`），行用逐行选择器订阅（选择变化只重渲染相关行）；模块级登记表按「组序」记录各列表的可见任务，Shift 连选按跨组顺序；登记变化时剔除已不可见（完成 / 收起 / 换视图）的选中项并刷新快照；`scopeKey`（视图 / 分组 / 空间筛选）变化即清空。
10. 手势：Mac 用 ⌘、其余平台用 Ctrl 点击切换（Mac 上 Ctrl+点击是右键）；Shift+点击连选（按下时阻止原生文字选区）；选择模式下点行切换、行前出方形复选框（`task-select`，与圆形勾选圈并存）；键盘 `x` 切换、Shift+J/K 扩选（组内）、Esc 清空；手机长按切换。均在捕获阶段处理，先于标题改名 / 胶囊。
11. 批量条（作用域内唯一一条）：已选 N · 全选当前视图（已加载、未收起的行）· 完成 · 日期 · 优先级 · 清单 · 空间 · 标签（点一下：全都有则移除，否则全部加上；按每条的本人标签算增删）· 状态 · 删除 · 退出。一律 `POST /tasks/batch`，按 100 条分块逐块提交；块内全有或全无，失败块提示首个失败项标题与原因（如有父 / 子任务不能单独换空间），已成功的块保留。
12. 撤销：批量完成 → 批量 `uncomplete`（服务端改为幂等：已非完成态跳过，不再 409 让整块回滚）；批量删除 → 批量 `restore`，只覆盖本人可恢复的（自己建的，或工作区 owner / admin——服务端 `requireTrashedTask`），其余在提示里说明。
13. 服务端：`batchTaskOpSchema` +`restore`、+`uncomplete`；顺带修：混合批量里删除项的空间未发实时失效（原先只看返回体的 spaceId），改为另查删除项空间合并发布。
15. 「刚变空先别卸载」（`useLinger`）：任务页的分组 / 整页、今日页的分段在最后一条被完成或移走后再保留 8.5 秒，否则组件一空就卸载，列表内的淡出与「撤销」随之丢失（今日页此前即有此问题，一并修复；debug/2026-10-01-task-undo-lost-when-group-empties）。
14. 乐观更新：`listId` 映射为 `list`、`tagIds` 映射为 `tags`（取清单 / 标签缓存），否则清单胶囊与标签要等请求返回才变。

## 候选与否决

- **单击选中、双击改名**（文件管理器式）：用户选「点标题即改名」。
- **只在任务页启用**：用户要全站一致。
- **每行常驻 4–5 个 Popover 与按钮**：万行列表滚动 P95 实测 33ms（超 20ms）——改为按需渲染 + 列表统一算权限与回调后回到预算内。
- **键盘拖拽 / 跨组 Shift+J/K**：焦点仍按组内管理，跨组扩选用 Shift+点击。
- **看板与日历**：卡片 / 日程块不是任务行，本轮不在范围；空间页只在列表视图启用选择与批量条。
- **收件箱去掉自带的「移到空间 / 状态」下拉**：分拣场景直观高效，保留，与菜单并存。
