# ADR-0029 文档栏：阅读 / 保存 / 字数移到标题下

> 状态：已采纳 · 2026-09-29 · 修订 ADR-0025 §1 与 ADR-0028 §1（工具栏第二行）。

## 背景

用户指出：吸顶工具栏第二行（阅读胶囊、专注、保存、Markdown、字数）不属于编辑格式，应放在顶部标题下面，并按类别整理。

分类：
- **阅读视图**：阅读胶囊（字体 / 纸张 / 排版 / 目录）、专注——所有人（含只读者）用，设一次管很久。
- **文档操作**：保存版本、Markdown 源码——可编辑者用，Ctrl+S 为主入口。
- **文档信息**：字数、上次保存版本时间——纯展示。

## 决定（用户 2026-09-29 选定「标题下方独立一行」）

1. **文档栏**（`DocBar`，REQ-READ-007 改）：标题下方独立一行、不吸顶、随正文滚走。左：字数 · 上次保存版本（相对时间，取最近一个手动保存 / 带标记的版本，复用历史列表查询）；右：「阅读」组（胶囊 + 专注）| 「文档」组（保存 + Markdown，仅可编辑者），两组之间细竖线分隔。窄屏保存 / Markdown 只显示图标。
2. **吸顶只剩格式一行**（REQ-EDITOR-024 注）：`EditorToolbar` 只渲染格式行（放不下收进「…」，ADR-0028）；只读者不再有吸顶条；< lg 隐藏（MobileToolbar 负责）。
3. **挂载方式**：记录页在标题下放插槽（预留 2.25rem 高度避免编辑器 chunk 加载时跳动），`EntryEditor` 经 React portal 把 `DocBar` 渲染进去（字数、保存、源码依赖编辑器与协同连接，都在 EntryEditor 内）。
