# ADR-0031 格式工具栏去卡片：素净一行 + 细线

> 状态：已采纳 · 2026-09-29 · 修订 ADR-0030 §1（格式栏卡片化）。

## 背景

用户反馈：卡片样式的格式工具栏（圆角浅底 + 边框 + 阴影）不好看，不要卡片。

## 决定

- 格式工具栏去掉底色块、边框、圆角、阴影：一行图标 + 下方一条**与正文等宽**的 1px 细线（不再像 ADR-0028 那样负外边距横贯整张纸面）。
- 吸顶：`top = 顶栏高度`，底色 = 纸面（随纸张），盖住滚上来的正文；吸住后（哨兵元素 IntersectionObserver → `data-stuck`）细线下加一道极淡阴影提示悬浮。
- 按钮规格（30px / 圆角 7px）、文档栏、阅读胶囊中性色、正文去焦点框维持 ADR-0030。

## 后果

- 06 材质表「编辑器吸顶工具栏」行注更新。CHANGELOG。无 REQ 变化。
- 代码：`app.css`（`.xz-editor-toolbar`、`[data-stuck]`、`.xz-tb-sentinel`）、`EditorToolbar.tsx`（哨兵 + 吸顶检测）。
