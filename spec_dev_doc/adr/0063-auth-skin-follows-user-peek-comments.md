# ADR-0063 认证页主题跟随本机上次登录者 · 任务 Peek 摊开关注者与评论

> 状态：已采纳 · 2026-10-22 · 修订 ADR-0060 §4（认证页一律套工作区默认主题）、ADR-0050（任务预览内容）。无迁移。需求区 00：REQ-UI-066；REQ-UI-064 · REQ-UI-007 注。

## 背景

用户（2026-10-22）：「登陆 login 主题和登陆后的主题设置保持同步」「任务左边弹出简介的时候，连详细内容也一起展开，不要只显示元数据」。

1. ADR-0060 §4 让认证页（登录 / 注册 / 邀请）一律套**工作区默认主题**，理由是「认证页不知道是谁」。结果：本人在「设置 → 主题」选了别的主题（或退出主题），退出登录后登录页换成默认主题，登录后又换回来，两边对不上。
2. 任务 Peek（ADR-0050）已摊开属性、完整描述与子任务，但详情里的**关注者**与**评论**不在预览里；多数任务没写描述（本地库 24 个任务只有 3 个有描述），预览就只剩属性，看起来「只有元数据」。

## 决定

### 1. 认证页跟随本机上次登录者（REQ-UI-066）

1. 登录后外观同步（`useAppearanceSync` → `applyLocal`）时写本机 `xz:skin-auth = user`。此后本机认证页沿用本人生效主题的缓存 `xz:skin`（含「无主题」= 原生），与登录后一致；退出登录时页面上本来就挂着本人主题，不再换。
2. 从没在本机登录过（无 `xz:skin-auth`）仍按 ADR-0060 §4 套工作区默认主题（`GET /skins/default`、缓存 `xz:skin-default`）。
3. `theme-init.js` 首帧按同一规则择 `xz:skin` / `xz:skin-default`，两种情况刷新都不闪。明暗 / 玻璃强度 / 图片强度本来就读本机缓存（即本人上次的值），不变。
4. 背景图 `GET /skins/:id/art` 改为公开（`public` 长缓存）：样式表来自本机缓存，退出登录后图也要能取。主题图是运维安装的装饰资源，不含工作区数据；列表 / 详情（含样式表）仍要登录，缩略图仍只放行默认主题。
5. 取舍：同一浏览器换人登录时，登录页先显示上一位的主题，登录后换成本人的——与系统锁屏沿用上次用户壁纸同理，可接受；主题已被卸载时登录页仍用缓存样式表（图 404 只是没背景），下次登录即纠正。

### 2. 任务 Peek 摊开关注者与评论（REQ-UI-007 注）

6. 属性区加「关注者」（`peek-watchers`），与详情同一查询键 `['task', id, 'watchers']`（`taskWatchersQuery`）。
7. 子任务之后加只读评论（`peek-comments`）：未解决线程连回复按时间摊开（作者 · 时间 · 正文，已删显示占位），已解决只计数「已解决 N 条」；回复 / 解决 / 删除仍去详情。与详情同一查询键 `['comments', 'task', id]`（`commentsQuery`）。
8. 记录 Peek 不变（仍是摘要）：记录正文要走完整编辑器渲染，留给后续。
