# ADR-0018 大类就地管理、在空间里就地新建（语雀式）、新建并关联

> 状态：已采纳 · 2026-09-27 · 修订 ADR-0014 §1「在目录节点下点新记录 = 子页」（扩展为：在空间里新建一律默认进目录）、REQ-UI-031 无关；其余为新增。第二期见 ADR-0019。

## 背景

用户反馈（2026-09-27）：

1. 不知道「大类」怎么创建和修改：入口只有 `/spaces` 页右上角「管理大类」（且仅 owner / admin 可见），侧栏、空间页都没有。
2. 在自己的空间里新建记录很麻烦：多数入口不带「建在哪」——在概览 / 目录 / 任务 / 记录页按 `e` 会悄悄落进个人空间，或沿用上次打开时的位置（一次性默认值被永久记住的 bug）；新建对话框看不到也改不了空间与目录位置；概览快捷按钮建的记录不进目录；记录页没有「新建子页面」；关联只能先建好再回来挑，没有「新建并关联」。

用户决定：大类权限维持 owner / admin；在空间里新建默认进目录；记录页按 `e` = 同级页（语雀）；分两期都做。

## 决定

1. **大类就地管理**（REQ-KB-008）：
   - 侧栏「空间」标题旁「管理大类」（owner / admin）打开原管理弹窗；每个大类分区标题悬停出 ⋯：改名（Enter 保存 / Esc 取消）· 改色（色块）· 在此大类新建空间 · 删除（确认；其下空间变未分类）。窄屏 ⋯ 常显。
   - 管理弹窗：颜色改为色块选择器，名称 Enter 即保存（原仅失焦保存）。
   - 空间卡片 ⋯ 菜单列出大类，点选即「移到大类」（`PATCH /spaces/:id {groupId, ifUpdatedAt}`，需 space.manage）。
   - 侧栏拖动时「未分类」始终作为放置区出现（全部已归类时也能拖回未分类）。
   - 大类写操作不带 `ifUpdatedAt`：与标签一致，属低冲突、仅管理员可写的工作区元数据（CLAUDE 不变量 6 的豁免，在此记录）。改图标不做（侧栏分区固定用 Layers 图标）。
2. **新建对话框显示并可改位置**（REQ-ENTRY-021）：顶部「建在」一行 = 空间下拉（可写的空间：个人空间 + 我为 admin / member 的空间；服务端 `can('entry.create')` 为准）› 目录位置下拉（目录顶层 / 不放进目录 / 作为某页的子页，列出该空间目录树）。换空间 → 回到目录顶层；模板推荐按所选空间类型。
3. **`e` 跟随上下文**（REQ-ENTRY-022）：`useNewEntry` 拆为「页面登记的上下文」（令牌式 `register`，卸载只撤自己那份，后登记者优先）与「一次性默认值」（按钮显式传入，只作用于这一次）；打开瞬间冻结有效默认值，打开期间上下文变化不影响表单。登记：空间概览 / 目录 / 任务页 = 本空间目录顶层；空间记录页签 = 目录顶层或所选节点之下；记录详情页 = **同级**（在目录里 → 同一父页；不在目录 → 也不进目录）；`/entries` 无空间 = 空（服务端落个人空间，不进目录）。概览快捷按钮带 `parentId: null`（进目录根）。
4. **新建子页面 / 新建并关联**（REQ-ENTRY-023、REQ-LINK-006）：
   - 记录 ⋯ 菜单：「新建子页面」（仅当本篇在目录里——服务端 placeNew 要求父页在目录中）、「新建关联记录」（同级 + 关联「相关」）。
   - 关联面板：「+ 新建并关联」按当前所选关联类型（相关 / 阻塞 / 起因于 / 解决）打开对话框，显示「关联到《A》· 类型」可移除。
   - `POST /entries` 新增可选 `linkFrom { entryId, kind ∈ relates|blocks|caused_by|resolves }`：事务外先按 `POST /links` 同一套 `can()` 校验源端（不可读 404、不可写 403，记录不落库），同事务插 `links(entry:entryId → entry:新记录, kind)`；`mentions` 只由正文派生，422。Bug 的「修复于」（反向 resolves）不在本期。

## 候选与否决

- 在空间里新建默认放「其余记录」：与语雀心智不符，用户选默认进目录。
- 记录页 `e` = 子页：层级越建越深；语雀是同级，对话框里一步可改为子页。
- 另设「新建并关联」专用接口：`POST /entries` 加可选字段即可，鉴权复用 links 的源端校验。
- 大类加 `ifUpdatedAt`：收益小、要改接口与弹窗；记为豁免。

## 后果

- 无迁移。00：+REQ-KB-008、REQ-ENTRY-021 ~ 023、REQ-LINK-006；REQ-KB-001 · 002 加注。02 §9 `POST /entries` +`linkFrom`。08 §2.5 补大类说明（原文缺失），§2.8 · §2.9 注位置行与 `e` 规则。glossary：+新建上下文、新建并关联。
