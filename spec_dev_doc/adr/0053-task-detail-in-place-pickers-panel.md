# ADR-0053 任务详情：就地打开 · 自定义字段选择器 · 计划按用户时区 · 常驻栏 ≥ 1280

> 状态：已采纳 · 2026-10-07 · 修订 ADR-0044 §B.8（常驻详情栏 ≥ 1440 → ≥ 1280，1280 ~ 1440 打开详情时收起清单栏）、08 §2.3 / §2.4（今日 / 收件箱打开详情 = 跳空间页 → 页内 `?task=`）、§2.7（属性用原生 select / datetime-local → 自定义选择器）、ADR-0050 §B.8（「计划暂保留原输入」）。无迁移。需求区 00：REQ-TASK-045 · 046；REQ-TASK-034 注。

## 背景

用户（2026-10-07）请我说明详情弹窗的设置后，对其中指出的四处不足说「把这几处都优化一下」：

1. 今日 / 收件箱打开详情会跳到 `/spaces/<slug>/tasks/<id>`，离开当前页，关闭后回到空间页而不是原处。
2. 详情标题旁仍是旧的小优先级图标；状态 / 优先级 / 指派是浏览器原生下拉，与任务行、Peek 的胶囊不一致。
3. 「计划」仍是 `datetime-local`，按浏览器时区换算；「截止」已按用户时区（ADR-0050）。
4. 常驻详情栏要 ≥ 1440 才出现，1280 ~ 1440 常见笔记本宽度上仍是遮挡列表的模态抽屉。

## 决定

### A. 就地打开（REQ-TASK-045）

1. 今日、收件箱加 search `task=<id>`：点「›」/ 回车 / 菜单「打开详情」只改 search，页面内渲染 `TaskDetailSheet`（右侧抽屉），关闭去掉 `task` 回到原处。空间页本就是父路由叠详情，日历本就页内打开，不变。
2. Peek 的「打开详情」/ 回车：当前在任务页、今日、收件箱时就地升级（设 `?task=`），其余页面仍跳空间详情路由。

### B. 字段选择器（REQ-TASK-046）

3. 标题下一行：状态胶囊 + 优先级胶囊（ADR-0052）+ 保存提示。
4. 状态 → `StatusPicker`（状态胶囊列表，当前项打勾）；优先级 → `PriorityPicker`，触发器显示优先级胶囊；指派 → 头像 + 名字的弹层列表（含「未指派」）。都在 `fieldset disabled` 内，只读用户不能点开。testid 保持 `field-status / field-priority / field-assignee`。
5. 截止与计划共用 `DateField`（同一个 `DuePicker`，含相对日期快选，按**用户时区**，弹层关闭时一次提交）；显示日期 + 明确时刻。不选时间 = 全天：截止落 23:59（同前），**计划落当天 00:00**（计划是开始时刻）。逾期的截止标红。

### C. 常驻详情栏（REQ-TASK-034 注）

6. 任务页 ≥ 1280 即用常驻详情栏（`variant="panel"`）。1280 ~ 1440 打开详情时收起清单栏（应用侧栏 240 + 清单栏 240 + 详情 416 会把列表挤到 ~380px），改在页头显示范围胶囊条（与窄屏同一组件），关闭详情后清单栏回来；≥ 1440 清单栏与详情并存。
7. 常驻栏 Esc 关闭（与 Sheet 一致）：按键来自栏内或焦点在 body 时关；来自列表（Esc = 清空选择）、别处输入框、弹层的不处理。

## 候选与否决

- **今日 / 收件箱也做常驻右栏**：两页是单列 + 速览栏（`WithRail`），再加详情栏要重排布局——先用页内抽屉，体验问题（离开页面）已解决。
- **1280 ~ 1440 保持抽屉**（ADR-0044 当时的取舍）：遮挡列表、不能边看边改；收起清单栏换胶囊条后列表宽度 ~620px，够用。
- **计划不选时间也落 23:59**（与截止同）：计划是「从哪天开始」，落在当天末尾会让「今日开始」的判断滞后一整天——落 00:00。
