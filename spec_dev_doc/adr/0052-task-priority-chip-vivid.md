# ADR-0052 任务优先级：鲜艳色 + 文字胶囊

> 状态：已采纳 · 2026-10-07 · 修订 04 §2.1「任务优先级色」（低 info · 中 primary · 高 warning · 紧急 danger → 鲜艳 9 色板 低 蓝 · 中 绿 · 高 橙 · 紧急 红）、ADR-0044 §D.17（行尾优先级旗标 → 胶囊）、REQ-TASK-009 / 035 的验收口径。无迁移。

## 背景

用户（2026-10-07）：「任务：优先级也需要显示，此外优先级的颜色也需要更加鲜明。」

现状：任务行只在行尾放一个 16px 的箭头 / 三角图标（无文字），颜色取语义色 info `#3b6fb6` · primary-text · warning `#c9822e` · danger `#b8433a`，偏灰暗，与旁边的空间名、日期胶囊混在一起不显眼；勾选圈 1.5px 描边 + 8% 浅底，几乎看不出优先级。

## 决定

1. 优先级色改取鲜艳 9 色板（ADR-0010），色系不变、更饱和：**低 = 蓝 · 中 = 绿 · 高 = 橙 · 紧急 = 红**。tokens.css 新增派生 token `--xz-prio-{1..4}-{solid,bg,fg}`（别名到 `--xz-palette-*`，两主题自动跟随；9 色板 fg / bg 已由 check-contrast 校验 ≥ 4.5）。`[data-priority]` / `[data-check-priority]` 设 `--xz-prio`（solid，勾选圈 / 旗标）、`--xz-prio-fg`、`--xz-prio-bg`。
2. 优先级**胶囊** `PriorityChip`（`.xz-prio-chip`）：图标 + 「紧急 / 高 / 中 / 低」，浅底 + 深字，样式同日期胶囊；用于任务行（窄屏只留图标）、看板卡片、Peek。无优先级不显示（任务行悬停仍露出灰旗可设置）。`PriorityIcon`（详情头部等仍用图标处）改取 `--xz-prio-fg`。
3. 勾选圈：有优先级时描边 2px、浅底 14%（原 1.5px / 8%）。
4. 不单靠颜色（04 §7）：胶囊带图标与文字，图标形状各级不同。

## 候选与否决

- **高 = 红、紧急 = 紫**（部分工具的配色）：与现有「紧急 = 危险红」的认知和逾期红一致性冲突——保留红给紧急。
- **中 = 黄**：黄色文字在浅底上对比度难达标、夜场发灰——中保持绿。
- **只把图标调亮、不加文字**：用户要「显示」，图标难以一眼读出级别——加文字。

## 后果

- 04 §2.1 注；00 REQ-TASK-009 · 035 注。
- e2e：REQ-TASK-009 改为断言胶囊（`task-prio-chip`、文字「高」、色值 = `--xz-prio-3-fg / -bg`、勾选圈 2px）。视觉基线无变化（画廊不含任务行）。
