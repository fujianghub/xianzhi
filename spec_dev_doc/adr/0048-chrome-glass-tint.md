# ADR-0048 侧栏与顶栏的玻璃：去白、背后补色

> 状态：已采纳 · 2026-10-02 · 修订 ADR-0047 §2（侧栏 / 顶栏改用专用材质，不再吃通用的白色渐变填充与内发光）、06 §3.1（底板多三团定向光晕）、§4 Sidebar / Topbar 行。无迁移。需求区 00：REQ-UI-050。

## 背景

用户（2026-10-02）在「流光」下问「为什么侧栏和顶栏还是白色」。在 4041 实测日场「流光」：

- **侧栏**：50% 白底，加 0.55 白的 135° 渐变填充，加 28% 白的内发光，再加 `brightness(1.04)`，顶部有效白度超过 80%。
- **顶栏**：34% 白底加同一条渐变。顶栏是 1200 × 56 的扁条，135° 渐变会铺满左边约 530px，所以左半段接近纯白。
- **背后无可透**：侧栏固定在内容旁边，永远没有内容从它后面滚过；顶栏在页面未滚动时也一样，只能透出底板光晕。而光晕的浓色区集中在四角，不在侧栏中段和顶栏中部。`saturate(220%)` 只能放大已有色度，背后本来就淡，放大后仍是淡色。
- **夜场正常**：深底加白色低透明度，本身就透出了光晕色。

## 决定

1. 侧栏、顶栏使用专用变量 `--xz-sidebar-bg`、`--xz-topbar-bg`、`--xz-chrome-fill`、`--xz-chrome-inner`。默认值指回原玻璃变量，「标准」档不变。
2. 三档日场预设下，chrome 不叠白色渐变和内发光，底色变透：
   - 清透：40% / 34%；
   - 晶亮：32% / 28%；
   - 流光：28% / 22%。
3. 底板新增三团**定向光晕**，专门供 chrome 去透：`--xz-wash-side-1`（侧栏上段，翡翠）、`--xz-wash-side-2`（侧栏下段，天蓝）、`--xz-wash-top`（顶栏中部，青绿）。日场清透最淡，晶亮和流光同值；流光没有再加浓，因为它的漂移层已经叠了两团光，再浓侧栏导航字会压不住。夜场不加定向光晕：深底被提亮后会压字，而且夜场本来就透色。
4. 三档日场的 `--xz-primary-soft` 加深为 `#c6ecd9`。纸面透出薄荷色后，原来的浅主色底（如迷你月历的节假日圆底）会融进背景。
5. `check-contrast` 的预设矩阵增加「侧栏上 / 侧栏下 / 顶栏」三类合成底，即 chrome 底色叠定向光晕，再叠每团底板光晕，共 440 项。同时修正叠加顺序：夜场先叠日场块、再叠夜场块，与 CSS 特异度一致，不按文件先后。减透明时 chrome 回落实底。

## 影响

- 日场流光、晶亮、清透的侧栏与顶栏透出翡翠、天蓝、青绿的渐变；夜场与「标准」档不变。
- `backdrop-filter` 数量不变；底板多三层 `radial-gradient`，静态，不动画。
