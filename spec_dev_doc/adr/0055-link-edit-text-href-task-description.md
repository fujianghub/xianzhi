# ADR-0055 链接编辑同时改显示文字与地址 · 任务描述支持网页链接

> 状态：已采纳 · 2026-10-09 · 修订 ADR-0054 §D（链接气泡「编辑」只改地址 → 文字与地址都可改；网页卡片加「编辑」；网页链接识别只在记录正文 → 任务描述 / 评论也有）。无迁移。需求区 00：REQ-LINK-009、REQ-TASK-049。

## 背景

用户（2026-10-09）在 ADR-0054 上线后：「任务清单详情这里也需要支持网页链接识别；网页链接识别增加一个编辑键，可以修改链接的显示以及网页链接的真实内容，比如显示为 xxx，实际为 https://xxx.yyy.com，二者都可以编辑。」

现状：任务描述 / 评论用 liteKit（不走 Yjs、存 PM JSON），只有 Tiptap 自带的 autolink，没有粘贴取标题、链接气泡、悬停预览；ADR-0054 的链接气泡「编辑」只有一个地址输入框，显示文字改不了；网页卡片没有编辑入口（只能「刷新」）。

## 决定

1. **链接气泡「编辑」**（记录正文与 liteKit 共用 `LinkBubble`）：两栏「显示文字」「链接地址」，预填当前值；开始编辑时记下链接范围（输入期间选区变化不改目标）。保存：地址清空 = 移除链接；显示文字清空 = 用地址作文字；地址走协议白名单（`isAllowedLink`）。回车保存、Esc 取消。testid `link-bubble-text` / `link-bubble-input` / `link-bubble-save`。
2. **网页卡片「编辑」**：悬停菜单加「编辑」，卡片原位换成两栏表单（标题 · 网址）。改网址 = 描述 / 站点名作废并按新网址重新抓；标题留空 = 用抓到的网页标题（标题为空时自动写回，不覆盖用户写的）。testid `link-card-edit` / `link-card-form`。
3. **任务描述 / 评论（liteKit）**：
   - 粘贴单个网址同记录正文（链接 + 异步换网页标题；本站记录链接转记录引用）；
   - Link 配置与正文同一套协议白名单（`isAllowedLink`、`defaultProtocol: https`）；
   - 可编辑时挂链接气泡（无「卡片」——liteKit 没有 `linkCard` 节点，`LinkBubble` 按 schema 自动隐藏）；只读时挂悬停预览；
   - `PmView`（Peek 里的任务描述、评论正文）同样有外链悬停预览（`LinkHoverCard` 改为可挂任意容器 `root`）。
4. 不给任务描述加网页卡片节点：要改服务端 `LITE_NODES` / `liteDocSchema`、PmView、导出与旧客户端兼容，收益小于成本；描述里的链接用「显示为 标题」已够读。

## 后果

- 00：+REQ-LINK-009、REQ-TASK-049。
- e2e：+`link-edit.spec`（正文链接编辑文字与地址、卡片编辑标题与网址、任务描述链接编辑并失焦保存）。
