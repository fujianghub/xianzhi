# ADR-0047 玻璃强度：默认「流光」，用户可选

> 状态：已采纳 · 2026-10-02 · 修订 06 §3.1（光晕三处 → 可多一团 + 流光漂移层）、§3.2（玻璃透明度与光边）、§4 纸面行；08 §2.13 个人页偏好。无迁移。需求区 00：REQ-UI-049。承接 ADR-0046。

> 注 2026-10-02：§1「本机偏好」已由 ADR-0049 改为随账号保存，工作区可设默认；本机 `xz:glass` 只作首帧缓存。

## 背景

用户（2026-10-02）看过 ADR-0046 的精修后反馈「玻璃质感不够强」。分析原因：

1. **背后几乎没有可透的东西**：底板是近乎纯色的 `#f4f4f1`，三团光晕的透明度只有 0.10 ~ 0.17 且缩在角落。对平滑渐变做模糊，得到的仍是同一片平滑渐变，所以玻璃看起来像带色的白板。
2. **玻璃太实**：日场 regular 为 62% 白，thick 和侧栏为 82% 白。
3. **大面积是实底纸面**：卡片、列表、统计卡都是 98% 实色。
4. **边缘光弱**：只有顶缘 1px 高光，没有方向性光边。

关键判断：既然背后是平滑光晕，玻璃感主要来自透明度、光边和渐变填充，模糊本身贡献很小。因此加强玻璃**不需要新增 `backdrop-filter`**。

## 决定

1. 新增本机偏好「玻璃强度」，写 `html[data-glass]`，取值 `liquid` 流光（**默认**）/ `vivid` 晶亮 / `clear` 清透 / `standard` 标准（= ADR-0046 外观，不写属性）。存于 `xz:glass`，默认值不存储；首帧前由 `theme-init.js` 应用；入口为「设置 → 个人 → 玻璃强度」，设计画廊工具栏有同一偏好的快捷切换。
2. 预设只调 token（`tokens.css`），不改布局、不加 blur：
   - 玻璃透明度：日场 thin / regular / thick，流光 22% / 34% / 50%，清透与晶亮 30% / 44% / 60%；饱和度 200% ~ 220%；`brightness` 1.04（夜场 1.08）。
   - 光边 `--xz-rim-hi / -lo`：左上亮、右下暗的 inset 投影，不用伪元素，不改定位。另有内发光 `--xz-glass-inner`。
   - 斜向渐变填充 `--xz-glass-fill`：左上更实、右下透出光晕，作用于 glass* / paper / 侧栏。
   - 光晕加浓，新增 `--xz-glow-4`（侧栏中段后方）。流光再加 `body::after` 漂移层：两团大光晕，38s 往返，只动 `translate`，减弱档静止。
   - 纸面底色走 `--xz-paper-bg`：晶亮 / 流光下为半透明（日场 46% / 38%），不 blur；**记录正文纸面 `.paper.xz-reading` 恒为实底**，保证阅读。
3. 对比度：预设内同步调整次要文字色（日场 `fg-muted` / `fg-faint` / `primary-text` 加深，夜场 `fg-muted` / `fg-faint` 提亮）；流光夜场光晕压低，因为漂移层会把两团光叠在一起。`scripts/check-contrast.ts` 解析预设块，在每团光晕峰值上（流光按两团叠加）检查玻璃与纸面上的文字，共 176 项。
4. 预设选择器同时覆盖嵌套 `[data-theme]` 容器（设计画廊「并排」）；减透明（系统或画廊模拟）下一律回落为实底，纸面也是。

## 影响

- 默认外观变化：全站更透、更亮，带光晕色；视觉基线（design）更新。
- 预算：`backdrop-filter` 数量不变；新增 1 个 fixed 漂移层（合成层动画，不重绘视口）。06 §8 光晕「3 个 radial-gradient」改为最多 4 + 漂移层 2。
- 不做：玻璃噪点（ADR-0005）；偏好随账号同步（与主题、动效档位一致，只存本机）。
