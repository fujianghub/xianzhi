# ADR-0051 任务页默认按清单分组

> 状态：已采纳 · 2026-10-07 · 修订 ADR-0050 §A.5（默认分组 已完成 = 不分组 · 文件夹 = 按清单 · 其余 = 按日期 → 一律按清单，单个清单 = 不分组）、ADR-0044 §B.10（`group` 缺省 = 按日期）。无迁移。需求区 00：REQ-TASK-044。

## 背景

用户（2026-10-07）先要求「默认显示按照『不分组』」，看过后改为「默认修改为按照『清单分组』」：任务按清单归类是主要的组织方式，打开任务页应先看到各清单的分类。

## 决定

1. URL 不带 `group`、本机也没记住选择时，任务页默认**按清单分组**（全部 / 智能清单 / 标签 / 已完成 / 文件夹）：组序同清单树，末尾「未归类」（文件夹视图没有）。
2. **单个清单**视图只有一个清单，按清单分组没有意义：缺省与带来的 `group=list` 都回落到**不分组**。
3. 记住选择的本机键改为 `xz.tasks.group.v3`：旧键里试用 ADR-0050 时记下的选择作废一次，否则已选过别的方式的浏览器看不到新默认；之后在下拉里选过的方式照旧记住。

## 候选与否决

- **默认不分组**（同日先实施、用户看过后改掉）：任务多时一长条，看不出分类。
- **默认按日期**（ADR-0044 起的旧默认）：日期组把同一清单的任务拆散，不符合以清单为主的用法。
- **沿用旧键**：改默认值对已选过的浏览器不生效，用户会以为没改——升版本键。

## 后果

- 00：+REQ-TASK-044。08 §2.3b 注。
- e2e：`tasks-page.spec` 需要日期分组的用例显式带 `group=date`；`tasks-groups.spec` 单清单回落断言改为 `none`，+REQ-TASK-044。
