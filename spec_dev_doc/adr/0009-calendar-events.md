# ADR-0009 日历改版：独立「日程」、重复与提醒、中国节假日（对标 macOS 日历）

> 状态：已采纳 · 2026-09-25 · 扩展 REQ-UI-031（原「事件 = 任务」改为日程 + 任务叠加层）；新增 REQ-CAL-001 ~ 009；表 `calendars` / `calendar_events`（01 §3.15）。

## 背景

用户要求：日历支持节假日标记；直接点击添加、编辑、删除；全面对标 macOS 日历；支持不同事项内容标记。现状日历只把任务（`dueAt / scheduledAt`）铺到月 / 周视图上，点开是任务 Peek，不能在日历上建东西，没有时长、没有分类、没有节假日。

任务不等于日程：任务有状态、指派、看板位置，时刻是「截止」而非「占用时段」；硬把会议塞进 `tasks` 会污染今日、收件箱、看板与通知。

## 决定

1. **独立实体**：`calendars`（个人日历 = 颜色分类，默认 个人 / 工作 / 学习 / 生活）+ `calendar_events`（定时 / 全天 / 跨天，地点、链接、备注、提醒）。**个人私有**：`calendar.read / calendar.write` 仅 owner 本人（admin 也不可见）。任务不迁移，作为可关闭的叠加层继续显示。
2. **重复**：存 RFC 5545 RRULE 子集（DAILY / WEEKLY / MONTHLY / YEARLY + INTERVAL / BYDAY / UNTIL / COUNT），服务端用 `rrule` 在事件时区的**本地墙钟**上展开（浮动时间），`GET /calendar-events?from&to` 返回「发生」。单次改写 = 独立行（`recurrence_id` + `original_start_at`）+ 母事件 `exdates`；改 / 删范围沿用 macOS 三选一：仅此 / 将来 / 全部（将来 = 截断母事件 UNTIL + 另起新系列）。不支持 BYSETPOS、每月第 N 个星期几等高级规则（后续按需）。
3. **节假日**：npm `chinese-days`（MIT，离线内置国务院每年发布的放假 / 调休安排，另含农历、节气、传统节日；约 32 KB，只随日历相关页面懒加载）。显示：「休」「班」角标、农历小字（节日 > 节气 > 农历日）、年视图与小月历着色；可在侧栏关闭。数据年更：每年 11 月前后国务院发布次年安排后升级依赖（当前覆盖到 2026 年，2027 年发布前不显示 2027 年的休 / 班，农历与节气不受影响）。只展示主要传统节日（白名单，数据源另含大量民俗诞辰）。
4. **提醒**：`alarms int[]`（开始前分钟数，全天事件相对当天 00:00，可为负），pg-boss 作业 `calendar.reminders` 每分钟扫描，触发时刻落在 (now − 5 min, now] 即 emit `calendar.reminder`（走 `events` 出箱，CLAUDE.md 不变量 3），按 events 去重保证每（日程, 发生时刻, 提前量）一次；停机错过不补发。
5. **交互**（macOS 同）：日 / 周 / 月 / 年视图 + 左栏（小月历、我的日历、叠加项、接下来）；空白处单击 / 拖选新建，点日程弹编辑器，拖动改期、拖底边改时长，月视图跨日拖放；乐观更新，失败回滚。

## 候选与否决

- **日程也存 `tasks`（加 `endAt`、`kind=event`）**：一张表少，但今日 / 收件箱 / 看板 / 通知 / 搜索全部要排除它，且任务的权限跟空间走，日程是个人的——否决。
- **前端展开 RRULE**：服务端仍需展开来算提醒，两处实现易分叉——否决，前端只拼 / 解析 RRULE 字符串用于编辑器。
- **自维护节假日 JSON**：零依赖，但每年要手工录入调休——否决，改为依赖升级（`chinese-days` 无运行时依赖，满足 05 §2 大包限制）。

## 后果

- 00 REQ-CAL-001 ~ 009、REQ-UI-031 加注；01 §3.15、§3.10 target_type 加 `calendar_event`、§4 事件 +1、§5 矩阵 +1；02 §9 +8 条路由；07 §5 限额；08 §2.17 改版；glossary 加「日程」「我的日历」「重复」「提醒」「休 / 班」。
- 新依赖 `rrule`（BSD-3，服务端）、`chinese-days`（MIT，前端 + shared）。
- 日程不进全文搜索、不进导出（后续需要时另议）；不支持共享日历 / 订阅 ICS（二期候选）。
