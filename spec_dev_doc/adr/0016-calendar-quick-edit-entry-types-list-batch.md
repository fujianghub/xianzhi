# ADR-0016 日历就地编辑、自定义记录类型、记录默认列表与批量编辑、侧栏「空间」可点

> 状态：已采纳 · 2026-09-27 · 修订 REQ-UI-031（点任务不再开 Peek）、REQ-ENTRY-001（kind 增 `custom`）、REQ-ENTRY-013（批量 op 扩充）、ADR-0014 §4（列表视图勾选常驻）与 08 §2.8 默认视图（卡片 → 列表）；其余为新增。

## 背景

用户反馈（2026-09-27）：

1. 日历里点任务只能打开只读 Peek，改、删都要跳到任务页；点日程弹整页模态。希望像 macOS 日历一样在原处直接改、删。
2. 记录只有「移动 / 标签 / 归档 / 删除」批量，改不了类型与状态，且批量入口藏在「多选」按钮后。
3. 类型是写死的 9 种，不能自定义；标签管理页已有，但记录页没有入口。
4. 记录页默认是卡片，看不到状态 / 进度。
5. 侧栏「空间」是可点的链接，却与不可点的「我的视图」同样灰色，分不出来。

## 决定

1. **日历快速编辑气泡**（REQ-CAL-012）：点日程 / 任务，在其旁弹出气泡（Popover 锚在被点元素的矩形上），不离开日历。
   - 日程：标题、全天、开始 / 结束、日历、地点、备注；点气泡外 / Esc 关闭时有改动即保存（macOS 行为），也可点「保存」；重复日程的范围询问放在路由级（气泡关闭后对话框仍在）。「更多选项…」打开原完整编辑器（重复 / 提醒 / 链接）。删除：重复日程问范围，否则直接删。
   - 任务：完成勾选、标题、日期 / 时间（改的是日历上用来定位它的字段：截止优先，否则计划开始；时间留空 = 全天 23:59）、优先级；删除 = 软删 + Toast「撤销」（restore）；「详情」在日历页内开任务详情抽屉。气泡内写操作串行、总用最新 `updatedAt`（避免回车存标题后失焦再存一次互相 409）。
   - 气泡打开时焦点在气泡本身：直接按 Delete / Backspace 删除。
2. **任务拖动改期**（REQ-CAL-013）：月视图拖到别的日期、周 / 日视图拖动改时刻（15 分钟吸附），平移上面那个定位字段并保留时刻；不能拖底边改时长。定时任务拖到 00:00 / 23:59 会被当成全天，夹到 00:15 / 23:45。
3. **自定义记录类型**（REQ-ENTRY-018 · 019）：
   - 新表 `entry_types(workspace_id, name 唯一, color ∈ 9 色, statuses jsonb 有序 0–12, created_by)`；`ENTRY_KINDS` 增 `custom`，`entries.type_id` 指向类型，check `(kind = 'custom') = (type_id is not null)`。
   - 自定义类型记录的 fields = `{ status?, progress?, dueDate? }`；status 须在该类型状态列表里（service 校验），新建未给取第一项；状态名不含 `, | =`（列表筛选分隔符）。
   - 权限同标签：创建 = 非 guest；改 / 删 = 管理员或创建者（`entry_type.create` / `entry_type.manage`，走 `can()`）。
   - 改状态列表：`renames` 一对一改名同步到记录；被移除的状态改为新列表第一项（空列表 = 去掉 status）。删类型：其下全部记录（含回收站）转为随笔、清空 fields，同事务并写审计 `entry_type.deleted`。
   - 内置类型不可删（有固定属性 schema、图标、正文模板），管理员可**隐藏**（新表 `hidden_entry_kinds`），只影响筛选条与新建菜单。
   - 模板只认内置类型（`entry_templates_kind_ck` 用 `BUILTIN_ENTRY_KINDS`）；自定义类型记录存为模板时落为随笔。导出 zip 按类型名分目录，frontmatter 带 `type`。
   - 列表筛选新增 `typeId`（逗号多值），与 `kind` 同给为「任一命中」。
   - 管理页 `/settings/types`；记录页类型筛选条与标签筛选旁各有「管理」入口（→ `/settings/types`、`/settings/tags`）。单篇记录的属性栏可改类型（PATCH `kind` + `typeId`）。
4. **默认列表视图**（REQ-ENTRY-016）：`/entries` 与空间记录页缺省为列表，`view=cards` 为卡片（`view=table` 兼容旧链接）。列 = 勾选 · 标题（目录路径 + 一行摘要）· 类型 · 状态（色胶囊 + 文字）· 进度（进度条 + %）· 单一类型时的其它字段 · 标签 · 空间 · 更新时间。
5. **批量编辑**（REQ-ENTRY-017）：列表勾选列常驻，表头全选；有选中即出吸底操作条（卡片仍用「多选」模式）。`POST /entries/batch` 新增 `retype { kind, typeId? }`（fields 按目标类型重建，保留仍合法的状态 / 进度；迭代 / 变更 / 复盘有必填属性，不在批量目标里）、`fields { set: { status?, progress? } }`（合并后按类型校验，不合法进 failed）、`pin` / `unpin`。改状态按所选记录的类型分组、只对该组下发。编辑类操作后保留选择，删除 / 归档 / 移动后只留失败项。
6. **侧栏「空间」标题可点**（REQ-UI-038）：`.xz-nav-label-link` = 正文色 + 半粗 + 右箭头；悬停变 `primary-text`、浅底、箭头右移；「我的视图」仍为 muted 纯标签。

## 候选与否决

- 自定义类型复用标签：标签是多值、无状态，表达不了「一篇记录属于哪一类」与状态流转——否决。
- 自定义类型带任意字段 schema（字段编辑器）：一期成本过高；先给状态 / 进度 / 截止日三项，覆盖「显示状态、进度」诉求。
- 内置类型的隐藏存进 `entry_types`（`builtin` 列）：一表两义、唯一约束复杂——改为独立小表。
- 类型筛选把自定义类型 uuid 塞进 `kind`：两处校验都要改且语义混杂——改为独立 `typeId` 参数。
- 日历点任务打开完整编辑模态：仍打断视线；气泡 + 「详情」抽屉两级更接近 macOS。
