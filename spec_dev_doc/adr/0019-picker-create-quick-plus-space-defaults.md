# ADR-0019 正文 `[[` 找不到就新建、侧栏 / 目录「+」、空间默认类型与模板

> 状态：已采纳 · 2026-09-27 · ADR-0018 的第二期；新增，不修订既有决定。

## 背景

ADR-0018 解决了「新建时建在哪」，第二期补齐语雀式的剩余入口：写正文时想链接的记录还不存在；侧栏与目录树上缺少就地「+」；学习 / 产品等空间每次新建都要手选类型和模板。

## 决定

1. **`[[` 找不到就新建**（REQ-EDITOR-023）：记录选择器在编辑器里多一行「新建《q》并插入」——仅当有输入、当前输入的查询都已返回（避免加载中回车重复创建）、且没有同名记录时出现。新记录为随笔，建在当前记录所在空间，作为当前记录的子页（当前记录不在目录 → 新记录也不进目录，同 ADR-0018 的同级规则）；建好即插入 `entryLink`，`mentions` 关联照常由正文派生。关联面板的选择器不出此行（那里用「新建并关联」）。
   - 搜索「当前空间优先」：先按当前空间查一次、再查全部，合并去重，当前空间的排在前面（真正优先，而非只在前 10 条里重排）。
2. **侧栏 / 目录「+」**（REQ-KB-009）：
   - 侧栏空间行悬停出「+」= 在该空间目录顶层新建（可写空间：个人空间或我为 admin / member；服务端 `can()` 为准）。
   - `DirTree` 增 `onNewChild` 回调：记录页位置导航、个人首页空间目录的节点悬停出「+」= 作为该页子页新建；可写与否由调用方按空间角色决定。窄屏常显。
3. **空间默认类型与模板**（REQ-KB-010）：`spaces +default_kind`（仅内置类型，check 约束）`+default_template_id`（`builtin:*` 或本工作区的**工作区**模板；个人模板别的成员用不了，422）。「编辑空间」里设置；新建对话框在打开时与切换空间时按目标空间预选，调用方显式给了类型 / 模板时不覆盖；默认类型若已被所有者删除（ADR-0017）则不预选。

## 候选与否决

- 空间默认自定义类型：自定义类型按人隔离（ADR-0017），他人无法使用——否决，只允许内置类型。
- `[[` 新建为同级页：正文里提到的概念通常属于本篇之下，子页更贴近「从这里展开」；关联面板 / `e` 仍是同级。
- 选择器前端重排代替空间查询：只能重排服务端前 10 条，不是真优先——否决。

## 后果
