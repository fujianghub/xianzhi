# ADR-0028 吸顶工具栏两行固定分工 · 正文焦点描边调淡

> 状态：已采纳 · 2026-09-28 · 修订 ADR-0026 §2（工具栏「放不下换行」）、ADR-0025 §1（工具栏布局）。

## 背景

用户反馈：切换版心宽度（窄 / 标准 / 宽 / 满栏）时，文档上方工具栏的行数与位置跟着变（窄时编辑组折两行、阅读胶囊挤到第三行靠右），不美观；正文获得焦点时的 2px 主色描边太重。

## 决定（用户 2026-09-28 选定「两行固定分工」）

1. **两行固定**（REQ-EDITOR-032 改）：
   - 第一行：格式——「+」插入 | 撤销 / 重做 / 清除 | 段落格式 | 加粗 / 斜体 / 下划线 / 删除线 / 更多样式 | 文字色 / 背景色 | 三种列表 / 引用 | 对齐 | 链接。**始终一行**：ResizeObserver 量各组宽度，放不下时从右往左整组收进「…」（`tb-overflow`）菜单，菜单里是同一功能的列表形态（颜色网格、对齐项、链接表单都可用）；「+」永远在行内。斜杠「链接」在链接组被收起时打开「…」。
   - 第二行：阅读胶囊 · 专注 · 保存 · Markdown 靠左，字数靠右；两行之间虚线分隔。只读者只有第二行；< lg 第一行隐藏（MobileToolbar）。
   - 行数与高度不随版心宽度变化。
2. **正文焦点描边调淡**：可编辑正文 `.xz-prose[contenteditable=true]:focus-visible` 改为 1px、`focus-color` 28% 透明度、外扩 6px、圆角；全局 `:focus-visible`（按钮、输入框等）不变，键盘可达性保留。

## 候选与否决

- **单行 + 「…」收纳，阅读胶囊挪到标题上方元信息行**：一行更省高度，但阅读设置离正文远；用户选两行分工。
- **工具栏脱离纸面铺满内容区**：不随版心变，但与纸面割裂；未选。
