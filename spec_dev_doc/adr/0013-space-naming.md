# ADR-0013 界面称呼改回「空间」

> 状态：已采纳 · 2026-09-26 · 修订 ADR-0012 §2（界面称呼）；不涉及代码结构、API、表与迁移。

## 背景

ADR-0012 把大类之下这一层（简斋、衔枝……）的界面称呼从「空间」先改为「知识库」，同日又改为「分类」。上线预览后用户决定改回「空间」。

## 决定

- 层级称呼：**大类 → 空间 → 记录**；界面、提示、规范统一用「空间」，与术语表原有定义（任务与记录的容器，隐喻「巢」）一致。
- 不属于任何大类的空间显示「未分类」（「分类」一名废弃后不再冲突）；新建 / 编辑时的选项为「不归类」。
- 代码、API、表名本就一直是 `space`，不变。

## 候选与否决

- 知识库：偏「资料库」，与同时承载任务的定位不符——用户否决。
- 分类：与「大类」语义重叠，且「未分类的分类」拗口——用户否决。
- 巢 / 卷 / 簿 / 项目：未采用。

## 后果

- 00 REQ-KB-002、glossary「空间」行加注；01 / 02 / 08 及代码注释、测试描述中的「分类」统一为「空间」；ADR-0012 头部与 §2 加注（不变量 8）。
